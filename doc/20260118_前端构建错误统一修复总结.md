## 修复建议

为了避免类似问题，建议：

1. **类型同步**: 前后端类型定义应该保持一致
2. **可选字段处理**: 所有可选字段使用时应提供默认值（使用 `??` 运算符）
3. **类型导出**: 确保所有需要的类型都在 index 文件中导出
4. **渐进增强**: 新功能的字段应该设为可选，避免破坏现有代码
5. **API 路径统一**: 使用一致的 API 路径规范（如 `/content/...` 而不是 `/roadmaps/.../content`）
6. **类型别名**: 为相似类型创建别名，便于迁移和兼容
