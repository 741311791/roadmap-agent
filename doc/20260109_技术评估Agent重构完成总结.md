## 四、技术细节

### Agent标准规范
所有Agent必须：
1. 继承自 `app.agents.base.BaseAgent`
2. 实现 `async def execute(self, input_data: Any) -> Any` 抽象方法
3. 使用Settings中的LLM配置（如QUIZ_PROVIDER, QUIZ_MODEL等）
4. 使用Jinja2模板加载器加载prompt
5. 使用structlog进行日志记录
6. 调用父类的 `_call_llm()` 或 `_call_llm_stream()` 方法

### 目录划分原则
- **agents/**: 存放所有基于LLM的Agent实现
- **services/**: 存放纯业务逻辑服务（可能封装CRUD，但不直接使用LLM）
- **crud/**: 数据访问层（直接操作数据库）
- **api/**: API路由层（处理HTTP请求/响应）
