# Tavily API速率限制环境变量统一配置

## 问题背景

### 原始报错
```
error='Your request has been blocked due to excessive requests. 
Please reduce the rate of requests. Verify you are using production API keys.'
error_type='UsageLimitExceededError'
key_prefix='tvly-dev-L...'
```

### 问题原因
- 当前代码未实施速率限制
- 开发环境key（`tvly-dev-*`）限制约为10-20次/分钟
- 内容生成阶段多个概念并发调用，瞬间请求量过大

## 解决方案：环境变量统一配置

### 设计原则
✅ **简单至上**：所有Tavily key使用统一的速率限制  
✅ **环境变量配置**：通过 `.env` 文件灵活调整，无需修改代码  
✅ **全局速率控制**：基于Redis的全局限制器，多进程共享状态

### 核心改进

#### 1. 添加环境变量配置 (`app/config/settings.py`)

```python
class Settings(BaseSettings):
    # Web Search 配置
    TAVILY_API_KEY: str | None = Field(None)
    TAVILY_API_KEY_LIST: str | None = Field(None)
    
    # ✅ 新增：速率限制配置
    TAVILY_RATE_LIMIT_PER_MINUTE: int = Field(
        10, 
        description="Tavily API 速率限制（每分钟请求数，开发环境建议10，生产环境可设置100）"
    )
    
    USE_DUCKDUCKGO_FALLBACK: bool = Field(True)
```

**配置示例 (`.env`)**：
```bash
# 开发环境
TAVILY_RATE_LIMIT_PER_MINUTE=10

# 生产环境
TAVILY_RATE_LIMIT_PER_MINUTE=100
```

#### 2. 简化速率限制器 (`app/utils/rate_limiter.py`)

```python
_tavily_rate_limiter: Optional[GlobalRateLimiter] = None

async def get_tavily_rate_limiter() -> GlobalRateLimiter:
    """
    获取全局 Tavily API 速率限制器单例
    
    速率限制从环境变量 TAVILY_RATE_LIMIT_PER_MINUTE 读取
    所有 Tavily API key 使用统一的速率限制
    """
    global _tavily_rate_limiter
    
    if _tavily_rate_limiter is None:
        # 从环境变量读取速率限制
        rate_limit = settings.TAVILY_RATE_LIMIT_PER_MINUTE
        
        _tavily_rate_limiter = GlobalRateLimiter(
            redis_client=redis_client,
            key_prefix="tavily_api",
            max_requests=rate_limit,  # 从环境变量读取
            window_seconds=60,
        )
        
        logger.info(
            "tavily_rate_limiter_initialized",
            max_requests=rate_limit,
            source="environment_variable",
        )
    
    return _tavily_rate_limiter
```

**特性**：
- ✅ **单例模式**：全局只有一个限制器实例
- ✅ **环境变量驱动**：从 `settings.TAVILY_RATE_LIMIT_PER_MINUTE` 读取
- ✅ **Redis共享**：多进程/多Worker共享速率状态
- ✅ **简单易维护**：代码量减少70%+

#### 3. 简化搜索工具 (`app/tools/search/tavily_api_search.py`)

```python
async def _rate_limited_request(self, func, *args, **kwargs):
    """带全局速率限制的请求包装器"""
    # 获取全局速率限制器（从环境变量配置）
    rate_limiter = await get_tavily_rate_limiter()
    
    async with self._search_semaphore:
        await rate_limiter.acquire(timeout=30.0)
        result = await asyncio.to_thread(func, *args, **kwargs)
        return result
```

**简化点**：
- ❌ 移除：Per-Key限制器
- ❌ 移除：动态速率推断
- ❌ 移除：Redis缓存查询
- ✅ 保留：全局统一限制
