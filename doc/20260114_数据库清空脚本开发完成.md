## 技术实现

### TRUNCATE CASCADE

```sql
TRUNCATE TABLE table_name RESTART IDENTITY CASCADE
```

**优势**:
- 自动处理外键约束
- 重置自增序列
- 比DELETE更快
- 立即释放磁盘空间

### 安全机制

**1. 环境检查**
```python
if settings.ENVIRONMENT == "production":
    logger.error("禁止在生产环境执行")
    sys.exit(1)
```

**2. 二次确认**
```python
response = input("请输入 'YES' 确认继续: ").strip()
return response == "YES"
```

**3. 事务保证**
```python
async with async_session_maker.begin() as session:
    for table in tables_to_clear:
        await truncate_table(session, table)
    await session.commit()
```

### 方式1：使用Makefile命令

```bash

```

### 方式2：直接运行脚本


### 执行流程

```
1. 环境检查 → 确认不是生产环境
2. 显示警告 → 展示将要清空的表信息
3. 用户确认 → 要求输入'YES'
4. 执行清空 → TRUNCATE CASCADE所有表
5. 显示结果 → 统计成功/失败数量
```

## 使用场景

### ✅ 适用场景

1. 开发环境重置
2. 测试数据清理
3. Schema迁移后清空旧数据
4. 本地开发调试

### ❌ 不适用场景

1. 生产环境（自动拒绝）
2. 部分数据清理
3. 需要数据备份的场景
