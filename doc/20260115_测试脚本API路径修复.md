# 测试脚本API路径修复

**日期**: 2026-01-15  
**类型**: Bug修复

## 问题背景

在完成大规模API路由重构后（将 `workflows/` 目录改为 `tasks/`），测试脚本 `test_roadmap_generation.py` 因使用旧的API路径导致404错误。

## 问题表现

```bash
❌ 请求失败: HTTP 404
响应: {"error":{"code":"NOT_FOUND","message":"Not Found",...}}
```

## 根本原因

API路由重构将工作流相关端点从 `/api/v1/workflows/generation/*` 迁移到 `/api/v1/tasks/*`，但测试脚本仍使用旧路径。

## 修复内容

### 1. 路线图生成端点

**旧路径**:
```python
"/api/v1/workflows/generation/generate"
```

**新路径**:
```python
"/api/v1/tasks/generate"
```

### 2. 任务状态查询端点

**旧路径**:
```python
f"/api/v1/workflows/generation/{task_id}/status"
```

**新路径**:
```python
f"/api/v1/tasks/{task_id}/status"
```

## API重构映射表

| 功能 | 旧端点 | 新端点 | 文件位置 |
|------|--------|--------|----------|
| 生成路线图 | `POST /api/v1/workflows/generation/generate` | `POST /api/v1/tasks/generate` | `tasks/generation.py` |
| 查询任务状态 | `GET /api/v1/workflows/generation/{task_id}/status` | `GET /api/v1/tasks/{task_id}/status` | `tasks/query.py` |
| 查询内容状态 | - | `GET /api/v1/tasks/{task_id}/content-status` | `tasks/query.py` |
| 批准路线图 | - | `POST /api/v1/tasks/{task_id}/approve` | `tasks/approval.py` |
| 拒绝路线图 | - | `POST /api/v1/tasks/{task_id}/reject` | `tasks/approval.py` |
| 重试任务 | - | `POST /api/v1/tasks/retry` | `tasks/retry.py` |

## 测试验证

修复后运行测试脚本应正常工作：

```bash
cd backend
uv run python scripts/test_roadmap_generation.py
```
