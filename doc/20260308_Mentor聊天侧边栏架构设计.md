## 二、SSE 事件协议（后端 → 前端）

后端通过 `text/event-stream` 推送如下事件，前端适配层负责映射为 assistant-ui 格式。

```
# 文字流式片段
event: text_delta
data: {"type": "text_delta", "content": "根据你的学习进度，"}

# 工具调用开始（前端立即显示 loading card）
event: tool_call_start
data: {"type": "tool_call_start", "tool_call_id": "call_abc", "tool_name": "get_concept_tutorial", "args": {"concept_id": "react-hooks"}}

# 工具调用结束（前端更新 card 显示结果）
event: tool_call_end
data: {"type": "tool_call_end", "tool_call_id": "call_abc", "tool_name": "get_concept_tutorial", "success": true, "result": {"title": "React Hooks 深入"}}

# 流结束
event: done
data: {"type": "done", "message_id": "msg_xxx"}

# 错误
event: error
data: {"type": "error", "message": "LLM 调用失败"}
```

> **关于思考过程**：对于 o1/o3 等推理模型，思考内容通过 `text_delta` 携带 `is_thinking: true` 标记区分。普通模型无思考事件。

### 3.2 `mentor_agent.py` 核心设计

使用 LangGraph `create_react_agent` + `astream_events` v2：

- `create_react_agent` 是 LangGraph 推荐的工具调用标准方式
- `astream_events` v2 精确分离 text / tool / chain 三类事件，天然映射 SSE 协议
- 不需要改造现有 `BaseAgent`，两者完全独立

```python
# app/agents/mentor_agent.py

from langchain_openai import ChatOpenAI
from langchain_core.tools import StructuredTool
from langgraph.prebuilt import create_react_agent
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage
from typing import AsyncGenerator

class MentorAgent:
    """
    基于 LangGraph 的 Mentor Agent

    支持两种模式:
    - companion: 伴学模式（答疑解惑，举一反三）
    - tutoring:  导学模式（苏格拉底式提问，费曼测试）
    """

    AGENT_MODES = {
        "companion": "companion_agent.j2",
        "tutoring":  "tutoring_agent.j2",
    }

    def __init__(self, settings):
        self.llm = ChatOpenAI(
            model=settings.MENTOR_MODEL,
            api_key=settings.MENTOR_API_KEY,
            base_url=settings.MENTOR_BASE_URL,
            streaming=True,
        )
        self.tools = self._build_langchain_tools()

    def _build_langchain_tools(self) -> list:
        """
        将现有 BaseTool 包装为 LangChain StructuredTool
        复用现有工具实现逻辑，不重复开发
        """
        from app.tools.mentor.get_concept_tutorial_tool import GetConceptTutorialTool
        from app.tools.mentor.get_user_profile_tool import GetUserProfileTool
        from app.tools.mentor.get_roadmap_metadata_tool import GetRoadmapMetadataTool
        from app.tools.mentor.mark_content_complete_tool import MarkContentCompleteTool

        tools = []
        for tool_cls in [GetConceptTutorialTool, GetUserProfileTool,
                          GetRoadmapMetadataTool, MarkContentCompleteTool]:
            base_tool = tool_cls()
            lc_tool = StructuredTool(
                name=base_tool.name,
                description=base_tool.description,
                args_schema=base_tool.args_schema,
                coroutine=base_tool.execute,   # 直接复用 execute 方法
            )
            tools.append(lc_tool)
        return tools

    async def stream_chat(
        self,
        messages: list[dict],
        agent_mode: str,
        roadmap_id: str,
        concept_id: str | None,
    ) -> AsyncGenerator[dict, None]:
        """
        流式对话，yield SSE 事件字典

        Args:
            messages:   历史消息列表 [{"role": "user/assistant", "content": "..."}]
            agent_mode: "companion" 或 "tutoring"
            roadmap_id: 当前路线图 ID（注入上下文）
            concept_id: 当前学习的概念 ID（可选）

        Yields:
            SSE 事件字典，前端直接 JSON 序列化后发送
        """
        system_prompt = self._build_system_prompt(agent_mode, roadmap_id, concept_id)
        graph = create_react_agent(self.llm, self.tools)

        input_messages = [SystemMessage(content=system_prompt)]
        for msg in messages:
            if msg["role"] == "user":
                input_messages.append(HumanMessage(content=msg["content"]))
            else:
                input_messages.append(AIMessage(content=msg["content"]))

        # astream_events v2: 精确分离 text / tool 事件
        async for event in graph.astream_events(
            {"messages": input_messages}, version="v2"
        ):
            kind = event["event"]

            # 文字流式片段
            if kind == "on_chat_model_stream":
                chunk = event["data"]["chunk"]
                if chunk.content:
                    yield {"type": "text_delta", "content": chunk.content}

            # 工具调用开始
            elif kind == "on_tool_start":
                yield {
                    "type": "tool_call_start",
                    "tool_call_id": event.get("run_id", ""),
                    "tool_name": event["name"],
                    "args": event["data"].get("input", {}),
                }

            # 工具调用结束
            elif kind == "on_tool_end":
                yield {
                    "type": "tool_call_end",
                    "tool_call_id": event.get("run_id", ""),
                    "tool_name": event["name"],
                    "success": True,
                    "result": event["data"].get("output", {}),
                }
```

### 3.3 `mentor.py` SSE 端点

```python
# app/api/v1/endpoints/learning/mentor.py

class MentorChatRequest(BaseModel):
    messages: list[dict]           # [{"role": "user/assistant", "content": "..."}]
    agent_mode: str                # "companion" | "tutoring"
    concept_id: str | None = None
    session_id: str | None = None  # 可选，用于追踪会话

@router.post("/roadmaps/{roadmap_id}/mentor/chat")
async def mentor_chat(
    roadmap_id: str,
    body: MentorChatRequest,
    user: CurrentUser,
    db: CurrentSession,
) -> StreamingResponse:
    """Mentor 流式对话 SSE 端点"""

    async def event_generator():
        try:
            async for event in mentor_service.stream_chat(
                roadmap_id=roadmap_id,
                user_id=user.id,
                messages=body.messages,
                agent_mode=body.agent_mode,
                concept_id=body.concept_id,
                db=db,
            ):
                yield f"data: {json.dumps(event, ensure_ascii=False)}\n\n"
        except Exception as e:
            yield f"data: {json.dumps({'type': 'error', 'message': str(e)})}\n\n"

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "X-Accel-Buffering": "no",       # 禁用 Nginx 缓冲，确保实时推送
            "Access-Control-Allow-Origin": "*",
        },
    )
```

### 4.3 `MentorRuntimeProvider`（LocalRuntime 核心）

```tsx
// lib/runtime/mentor-runtime-provider.tsx
"use client";

import { useLocalRuntime, AssistantRuntimeProvider, type ChatModelAdapter } from "@assistant-ui/react";
import { fetchEventSource } from "@microsoft/fetch-event-source";

function createMentorAdapter(
  roadmapId: string,
  conceptId: string | null,
  agentMode: "companion" | "tutoring",
): ChatModelAdapter {
  return {
    async *run({ messages, abortSignal }) {
      // 累积状态必须在循环外部，否则工具调用 UI 会闪烁消失
      let accumulatedText = "";
      const toolCallsMap = new Map();

      const eventQueue: any[] = [];
      let resolve: (() => void) | null = null;
      let done = false;

      fetchEventSource(`/api/v1/learning/roadmaps/${roadmapId}/mentor/chat`, {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          Authorization: `Bearer ${getToken()}`,
        },
        body: JSON.stringify({
          messages: messages.map(convertToBackendMessage),
          agent_mode: agentMode,
          concept_id: conceptId,
        }),
        signal: abortSignal,
        onmessage(event) {
          const data = JSON.parse(event.data);
          eventQueue.push(data);
          resolve?.();
        },
        onclose() { done = true; resolve?.(); },
        onerror(err) { throw err; },
      });

      while (!done || eventQueue.length > 0) {
        if (eventQueue.length === 0) {
          await new Promise<void>((r) => { resolve = r; });
        }
        const event = eventQueue.shift();
        if (!event) continue;

        switch (event.type) {
          case "text_delta":
            accumulatedText += event.content;
            break;
          case "tool_call_start":
            toolCallsMap.set(event.tool_call_id, {
              type: "tool-call",
              toolCallId: event.tool_call_id,
              toolName: event.tool_name,
              args: event.args,
            });
            break;
          case "done":
            return;
          case "error":
            throw new Error(event.message);
        }

        // 每个事件后 yield 完整累积状态（保证工具调用不闪烁）
        yield {
          content: [
            ...(accumulatedText ? [{ type: "text" as const, text: accumulatedText }] : []),
            ...Array.from(toolCallsMap.values()),
          ],
        };
      }
    },
  };
}

export function MentorRuntimeProvider({
  roadmapId,
  conceptId,
  agentMode,
  children,
}: {
  roadmapId: string;
  conceptId: string | null;
  agentMode: "companion" | "tutoring";
  children: React.ReactNode;
}) {
  const adapter = useMemo(
    () => createMentorAdapter(roadmapId, conceptId, agentMode),
    [roadmapId, conceptId, agentMode]
  );
  const runtime = useLocalRuntime(adapter);

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

## 五、消息历史管理策略

| 方案 | 优缺点 | 推荐阶段 |
|---|---|---|
| **前端内存（in-memory）** | 零成本，页面刷新后丢失 | MVP P0 |
| **后端 DB 持久化** | 需新增 `ChatSession` + `ChatMessage` 表 | P2 |
| **assistant-ui ThreadHistoryAdapter** | 可无缝对接后端历史接口，无需改动 Thread 组件 | P2 |

P2 阶段通过 `ThreadHistoryAdapter` 接入 FastAPI 历史接口时，只需在 `MentorRuntimeProvider` 中增加 `adapters.history` 配置，Thread 组件本身不需要改动。

## 七、关键风险与注意事项

| 风险 | 说明 | 处理方案 |
|---|---|---|
| **工具调用 UI 闪烁** | 流式更新时若不累积 toolCallsMap，工具卡片会消失 | 严格在循环外部维护 `toolCallsMap`，每次 yield 完整累积状态 |
| **两个 Prompt 文件内容重复** | `company_agent.j2` 和 `tutorin_agent.j2` 当前内容完全一样 | P0 必须先重写 `companion_agent.j2` 以体现差异化 |
| **`mark_content_complete` 有副作用** | 该工具写入 DB，不能使用 SSE 请求的长事务 Session | 工具内部已使用 `async_session_maker()` 独立 Session，无需额外处理 |
| **上下文长度膨胀** | 长对话 + 多轮工具结果导致 token 超限 | MentorService 中实现消息裁剪：保留最近 N 轮 + system prompt |
| **agentMode 切换时 Runtime 重建** | 切换模式后 adapter 需要更新 | 将 `agentMode` 作为 key 传入 Provider，变化时重新创建 adapter |
| **Nginx 缓冲** | 生产环境 Nginx 默认缓冲 SSE 响应，导致延迟推送 | 响应头增加 `X-Accel-Buffering: no` |
