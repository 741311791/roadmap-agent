## 二、数据清理

### 重复数据清理结果

- ✅ **resource_recommendation_metadata**: 无重复数据
- ✅ **quiz_metadata**: 无重复数据
- ✅ **tutorial_metadata**: 不适用（支持版本管理）

### 清理 SQL

```sql
-- 清理 Resource 重复数据（保留最新的）
DELETE FROM resource_recommendation_metadata
WHERE id IN (
    SELECT id FROM (
        SELECT id, 
               ROW_NUMBER() OVER (
                   PARTITION BY roadmap_id, concept_id 
                   ORDER BY generated_at DESC
               ) as rn
        FROM resource_recommendation_metadata
    ) t
    WHERE rn > 1
);

-- 清理 Quiz 重复数据（保留最新的）
DELETE FROM quiz_metadata
WHERE quiz_id IN (
    SELECT quiz_id FROM (
        SELECT quiz_id, 
               ROW_NUMBER() OVER (
                   PARTITION BY roadmap_id, concept_id 
                   ORDER BY generated_at DESC
               ) as rn
        FROM quiz_metadata
    ) t
    WHERE rn > 1
);
```
