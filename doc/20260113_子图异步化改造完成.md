# 子图内容生成异步化改造完成总结

**日期**: 2026-01-13  
**改造范围**: 单 Concept 内容生成子图  
**架构升级**: 同步执行 → Celery 异步执行

---

## 一、改造背景

### 原有问题
1. **阻塞 HTTP 请求**: 子图内容生成耗时 30-60 秒，阻塞 FastAPI Worker
2. **可扩展性差**: 无法水平扩展内容生成任务
3. **用户体验差**: 前端长时间等待响应
4. **资源利用率低**: FastAPI Worker 被长时间占用

### 改造目标
- ✅ 将内容生成任务提交到 Celery Worker 异步执行
- ✅ FastAPI 进程立即返回任务 ID
- ✅ 支持任务状态查询和实时进度推送
- ✅ 遵循现有架构规范（路线图生成任务模式）

---

## 二、架构变更

### 改造前（同步架构）

```
用户请求
  ↓
FastAPI API 层
  ↓
SubgraphService.generate_single_concept_content()
  ↓ (阻塞 30-60 秒)
返回完整结果
```

**问题**:
- FastAPI Worker 长时间阻塞
- 无法并发处理多个内容生成请求
- 超时风险高

### 改造后（异步架构）

```
用户请求
  ↓
FastAPI API 层
  ↓ (立即返回 Task ID)
Celery 任务分发
  ↓
Celery Worker 执行
  ↓
SubgraphService.generate_single_concept_content()
  ↓
WebSocket 实时推送进度
  ↓
任务完成/失败通知
```

**优势**:
- ✅ FastAPI 立即响应（< 100ms）
- ✅ 支持水平扩展 Celery Worker
- ✅ 任务失败自动重试
- ✅ 实时进度推送

async def get_task_status(celery_task_id: str) -> ResponseModel:
    """查询 Celery 任务状态"""
    task_result = AsyncResult(celery_task_id, app=celery_app)
    
    return response_base.success(data={
        "celery_task_id": celery_task_id,
        "status": task_result.state,  # PENDING/STARTED/SUCCESS/FAILURE
        "result": task_result.result if task_result.ready() else None,
    })

## 四、使用流程

### 前端调用流程

```javascript
// 1. 提交内容生成任务
const response = await fetch('/api/v1/content/subgraph/generate-single-concept', {
  method: 'POST',
  body: JSON.stringify({
    roadmap_id: 'xxx',
    concept_id: 'yyy',
    force_regenerate: true,
  }),
});

const { data } = await response.json();
const { celery_task_id, status, message } = data;

// 2. 订阅 WebSocket 实时推送
const ws = new WebSocket(`ws://localhost:8000/ws/roadmap:${roadmap_id}`);
ws.onmessage = (event) => {
  const notification = JSON.parse(event.data);
  
  if (notification.event_type === 'concept_generation_started') {
    console.log('内容生成开始');
  }
  
  if (notification.event_type === 'concept_complete') {
    console.log('内容生成完成', notification.data);
  }
  
  if (notification.event_type === 'concept_generation_failed') {
    console.error('内容生成失败', notification.data.error);
  }
};

// 3. 可选：轮询任务状态（备用方案）
const pollStatus = async () => {
  const statusResponse = await fetch(
    `/api/v1/content/subgraph/task/${celery_task_id}/status`
  );
  const { data } = await statusResponse.json();
  
  if (data.status === 'SUCCESS') {
    console.log('任务完成', data.result);
  } else if (data.status === 'FAILURE') {
    console.error('任务失败', data.error);
  } else {
    setTimeout(pollStatus, 5000); // 5 秒后再次查询
  }
};

pollStatus();
```
