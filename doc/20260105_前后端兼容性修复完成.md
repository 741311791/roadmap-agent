## 🔧 关键变更说明

### 1. WebSocket 连接安全增强

**后端**：
```python
# 添加 JWT Token 验证
@router.websocket("/ws/{task_id}")
async def websocket_endpoint(
    websocket: WebSocket,
    task_id: str,
    token: str = Query(None),  # ✅ 必需的 Token 参数
):
    # 验证 Token 并检查权限
    if not token or not valid or task.user_id != user_id:
        await websocket.close(code=status.WS_1008_POLICY_VIOLATION)
        return
```

**前端**：
```typescript
// 自动附加 Token 到 WebSocket URL
const token = localStorage.getItem('access_token');
let wsUrl = `${baseUrl}/ws/${taskId}?include_history=true`;
if (token) {
  wsUrl += `&token=${encodeURIComponent(token)}`;  // ✅
}
```

## 🎯 安全策略（Fail Fast）

### 强制认证

- ✅ **WebSocket 必须有 Token**（无 Token 直接抛出异常）
- ✅ **快速失败**（立即发现问题，不浪费资源）
- ✅ **清晰错误**（明确的错误信息，便于调试）

### 错误处理

- ✅ 无 Token 时立即抛出异常（不尝试连接）
- ✅ 登出 API 失败时仍会清除本地存储
- ✅ 封面图生成失败不影响路线图显示

## 📝 注意事项

### 开发者须知

1. **WebSocket 连接**：
   - 必须在登录状态下使用
   - Token 会自动从 localStorage 获取
   - 日志中 Token 会被隐藏（`***`）

2. **登出功能**：
   - 使用新端点 `/auth/logout`
   - Token 会立即失效（加入黑名单）
   - 本地存储会被清除

3. **Celery 任务**：
   - 封面图生成改为异步
   - 需要 Celery Worker 运行
   - 可以通过 task_id 查询状态

## 🔍 问题排查

### Q1: WebSocket 连接失败（1008错误）

**原因**：Token 无效、过期或不存在

**解决**：
```typescript
// 检查 Token
const token = localStorage.getItem('access_token');
console.log('Token exists:', !!token);

// 重新登录
authService.logoutAsync().then(() => router.push('/login'));
```

### Q2: RequestID 响应头缺失

**原因**：服务器未重启

**解决**：
```bash
# 重启 uvicorn
# 在运行 uvicorn 的终端按 Ctrl+C，然后重新启动
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Q3: 封面图生成失败

**原因**：Celery Worker 未运行

**解决**：
```bash
# 启动 Celery Worker
celery -A app.core.celery_app worker --loglevel=info
```
