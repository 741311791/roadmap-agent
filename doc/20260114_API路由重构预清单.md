# API路由重构预清单

## 📋 目的
根据业务功能重新梳理和归类所有API接口，消除当前目录结构中的混乱和不合理归属。

## 🔍 当前问题
1. **users/** 目录包含了不属于用户管理的接口：
   - 获取路线图列表 (应属于roadmaps)
   - 获取回收站路线图 (应属于roadmaps)
   - 获取用户任务列表 (应属于tasks)
   - waitlist管理 (应属于admin)

2. **roadmaps/** 目录部分接口可以更精细分类
3. **workflows/** 和任务管理相关接口分散
4. 缺少独立的任务管理(tasks)目录
