# 节点数据传递完整性修复 (20260114)

## 问题概述

路线图生成流程中，`roadmap_metadata` 表未能成功持久化数据，导致后续节点因外键约束失败。

### 问题现象

1. 日志显示 `curriculum_design` 节点"执行成功"
2. 数据库中没有对应的 `roadmap_metadata` 记录
3. 后续 `fan_in_and_save` 节点插入 `tutorial_metadata` 时触发外键约束错误：
   ```
   ForeignKeyViolationError: insert or update on table "tutorial_metadata" violates foreign key constraint "tutorial_metadata_roadmap_id_fkey"
   DETAIL: Key (roadmap_id)=(python-fullstack-engineer-b4k9m2n7) is not present in table "roadmap_metadata"
   ```

---

## 根因分析

### 架构设计回顾

**LangGraph 节点与 Handler 的职责分离**：

```
节点 (Node)  →  输出 (Output Dict)  →  Handler  →  数据库
  ↓                    ↓                    ↓
执行Agent         返回纯数据           持久化数据
```

**问题根源**：节点返回的 `output` 字典中缺少 Handler 保存数据所需的必填字段。

### 具体案例分析

#### 案例1：curriculum_design 节点

**Handler 需要的数据**：
```python
# backend/app/core/orchestrator/handlers/curriculum_handler.py
async def _handle_output(self, output: dict, task_id: str, session: AsyncSession):
    framework = output.get("roadmap_framework")  # ✅ 节点返回了
    roadmap_id = output.get("roadmap_id")        # ❌ 节点没返回
    user_id = output.get("user_id")              # ❌ 节点没返回
    
    await roadmap_crud.save_roadmap_metadata(
        session,
        roadmap_id,  # ❌ None
        user_id,     # ❌ None
        framework,
    )
```

**节点原返回值**：
```python
# backend/app/core/orchestrator/nodes/curriculum_design.py (修复前)
return {
    "roadmap_framework": framework,  # ✅ 有
    "current_step": "curriculum_design",
    "execution_history": ["课程设计完成"],
    # ❌ 缺少 roadmap_id
    # ❌ 缺少 user_id
}
```

**结果**：
- `roadmap_crud.save_roadmap_metadata()` 被调用
- 但 `roadmap_id=None`, `user_id=None`
- 数据库插入失败或创建了不完整的记录

---

## 修复方案

### 核心原则

**节点输出必须包含 Handler 所需的所有字段**

### 修复策略

1. 检查每个节点对应的 Handler 需要哪些字段
2. 在节点返回值中补全这些字段
3. 字段来源：
   - 从 `state` 中提取（如 `roadmap_id`）
   - 从 Agent 输出中提取（如 `framework`）
   - 从输入参数中提取（如 `user_id` 从 `user_request` 中获取）

## 架构最佳实践总结

### 规则1：节点输出完整性检查清单

在编写节点时，必须检查：

1. **读取对应 Handler 的代码**，确定需要哪些字段
2. **在 `return` 语句中包含所有必需字段**
3. **添加注释标记** `⚠️ 必须包含 Handler 需要的所有字段`

**模板**：
```python
async def my_node(state: RoadmapState, config: RunnableConfig) -> dict:
    # ... 执行逻辑 ...
    
    # 返回纯数据（不保存数据库）
    # ⚠️ 必须包含 Handler 需要的所有字段
    return {
        # ✅ Handler 需要的字段1
        "field1": value1,
        # ✅ Handler 需要的字段2
        "field2": state.get("field2"),
        # ✅ Handler 需要的字段3
        "field3": state["user_request"].field3,
        # 节点状态字段
        "current_step": "my_node",
        "execution_history": ["我的节点完成"],
    }
```

### 规则2：Handler 字段来源声明

在 Handler 的 Docstring 中明确声明需要的字段：

```python
async def _handle_output(
    self,
    output: dict,
    task_id: str,
    session: AsyncSession,
) -> None:
    """
    处理节点输出（具体实现）
    
    Args:
        output: 包含以下必需字段
            - field1: 说明
            - field2: 说明
            - field3: 说明
        task_id: 任务ID
        session: 数据库会话
    """
    ...
```

### 规则3：字段获取优先级

1. **从 Agent 输出获取**：节点执行的核心数据
2. **从 state 获取**：工作流全局状态中的共享数据
3. **从输入参数获取**：如 `user_request.user_id`

   - 补全所有节点返回值中 Handler 需要的字段

**关键要点**：
- ✅ 节点返回值必须包含 Handler 所需的所有字段
- ✅ 字段来源：Agent 输出 > State > 输入参数
