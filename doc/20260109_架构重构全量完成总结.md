## 🎓 关键学习点

### 1. Cache-Aside 模式
```python
# 标准模式：先查缓存，未命中则查数据库并缓存
cached = await redis.get(key)
if cached:
    return cached

data = await db.query(...)
await redis.set(key, data, ttl)
return data
```

### 2. 中间件执行顺序
```python
# ⚠️ LIFO (后进先出)
app.add_middleware(A)  # 最内层，最后执行
app.add_middleware(B)  # 中间层
app.add_middleware(C)  # 最外层，最先执行

# 执行顺序：C → B → A → 业务逻辑 → A → B → C
```

### 3. Celery Worker 数据库隔离
```python
# 关键：每个 Worker 子进程需要独立的数据库连接
@worker_process_init.connect
def on_worker_process_init(**kwargs):
    reset_engine_cache()  # 清空继承的 engine 缓存
```

### 4. Prometheus 指标重复注册保护
```python
def _get_or_create_counter(name: str, ...):
    if name not in _metrics_cache:
        try:
            _metrics_cache[name] = Counter(name, ...)
        except ValueError:
            # 从 registry 中获取已注册的
            ...
```
