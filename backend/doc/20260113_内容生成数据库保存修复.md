# 内容生成数据库保存修复

**日期**: 2026-01-13  
**状态**: ✅ 已完成

## 问题根因

根据终端日志分析（行510），内容生成阶段虽然成功生成教程内容并上传到 S3，但**数据库中没有保存任何元数据**。

## 关键日志分析

### 1. **主要问题：roadmap_id 缺失**（行510）
```
content_handler_missing_roadmap_id task_id=63551bca-2e40-413c-aee1-de51f8bf29fd
```

**原因**：`content_generation_node` 返回值中缺少 `roadmap_id` 字段，导致 `ContentHandler` 无法保存到数据库。

---

### 2. **次要问题：TavilyKeyRepository 未定义**（行54, 106, 228, 307）
```python
error="name 'TavilyKeyRepository' is not defined"
```

**原因**：`TavilyAPISearchTool` 中使用了不存在的 `TavilyKeyRepository` 类，应使用 `TavilyKeyManager`。

---

### 3. **副作用：数据库连接池冲突**（行24-103）
```python
IllegalStateChangeError: Method 'close()' can't be called here
```

**原因**：`get_db_transaction()` 在并发场景下存在异步上下文管理器冲突（由搜索工具调用触发）。

---

### 4. **节点名称说明**（⚠️ 这不是问题，是正常设计）
- **主图节点**：`content_generation`（行494）← 已重命名修复
- **子图节点**：`generate_tutorial`, `generate_resource`, `generate_quiz`（行131, 157等）

**设计说明**：
- 子图节点是内部并行执行单元，不需要单独的 Handler
- 它们的输出会被自动聚合（Reducer）
- 只有主图节点 `content_generation` 有对应的 `ContentHandler`
- 日志中的 `handler_not_found node_name=generate_tutorial` 是**正常现象**，不是错误

---

## 修复方案

### 修复1：添加 roadmap_id 到返回值

**文件**：`backend/app/core/orchestrator/nodes/content_generation.py`

```python
# ❌ 修复前
return {
    "tutorial_refs": {...},
    "resource_refs": {...},
    "quiz_refs": {...},
    "failed_concepts": [...],
    "current_step": "content_generation",
    "execution_history": [...]
}

# ✅ 修复后
return {
    "roadmap_id": roadmap_id,  # 添加此字段
    "tutorial_refs": {...},
    "resource_refs": {...},
    "quiz_refs": {...},
    "failed_concepts": [...],
    "current_step": "content_generation",
    "execution_history": [...]
}
```

---

### 修复2：修复 TavilyKeyRepository 引用错误

**文件**：`backend/app/tools/search/tavily_api_search.py`

```python
# ❌ 修复前
self.repo = TavilyKeyRepository(db_session) if db_session else None

# 后续使用
if self.repo:
    key_record = await self.repo.get_best_key()

# ✅ 修复后
self._db_session = db_session

# 后续使用
if self._db_session:
    from app.core.tavily_key_manager import TavilyKeyManager
    from app.models.database import TavilyAPIKey
    
    manager = TavilyKeyManager(TavilyAPIKey)
    key_record = await manager.get_best_key(self._db_session)
```
