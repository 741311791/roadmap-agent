## 🔧 技术实现细节

### 1. 单例模式统一实现

所有 CRUD 文件都采用相同的单例模式：

```python
# 全局单例变量
_crud_instance: Optional[CRUDClass] = None

# 单例获取函数
def get_crud() -> CRUDClass:
    global _crud_instance
    if _crud_instance is None:
        _crud_instance = CRUDClass(Model)
    return _crud_instance
```

**优势**:
- 全局唯一实例
- 延迟初始化
- 线程安全（Python GIL 保证）

### 2. TYPE_CHECKING 导入策略

避免循环导入问题：

```python
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from app.models.domain import DomainModel
```

**原理**:
- 仅在类型检查时导入
- 运行时不导入（避免循环依赖）
- 保持类型注解完整性

### 3. 统一的方法签名

所有 CRUD 方法遵循统一签名：

```python
async def method_name(
    self,
    session: AsyncSession,  # 第一个参数：数据库会话
    primary_key: str,       # 第二个参数：主键/查询条件
    *,                      # 可选参数使用关键字参数
    optional_param: Optional[Type] = None,
) -> ReturnType:
    """方法文档字符串"""
    pass
```

## 🎓 重构经验与最佳实践

### 何时进行激进式重构

**推荐情况**:
- ✅ MVP 阶段，无历史包袱
- ✅ 文件过大（> 500 行）且职责混乱
- ✅ 有清晰的重构目标和规范
- ✅ 有完整的测试覆盖
- ✅ 团队达成共识

**不推荐情况**:
- ❌ 生产环境运行中的核心模块
- ❌ 无测试覆盖
- ❌ 依赖关系复杂难以梳理
- ❌ 时间紧迫

### 激进式重构的关键步骤

1. **充分调研**: 使用 grep 查找所有引用点
2. **分阶段执行**: 逐个抽离，降低风险
3. **立即验证**: 每次抽离后立即测试
4. **批量更新**: 同时更新所有引用点
5. **彻底清理**: 删除原文件，不留后路
