# 搜索工具空查询修复

**日期**: 2026-01-13  
**状态**: ✅ 已完成

## 问题描述

### 报错信息
```
Error in engine yahoo: AttributeError("'NoneType' object has no attribute 'lower'")
Error in engine brave: AttributeError("'NoneType' object has no attribute 'lower'")
Error in engine duckduckgo: AttributeError("'NoneType' object has no attribute 'lower'")
```

### 根因分析
LLM 在调用 `web_search` 工具时，传递了空的 `query` 参数（`None` 或空字符串），导致搜索引擎（DuckDuckGo、Searx 等）尝试调用 `.lower()` 方法时报错。

---

## 修复方案

### 1. 搜索工具层面添加验证

**DuckDuckGo 搜索工具**（`app/tools/search/duckduckgo_search.py`）:
```python
async def execute(self, input_data: SearchQuery) -> SearchResult:
    # ✅ 添加查询验证
    if not input_data.query or not input_data.query.strip():
        logger.error(
            "duckduckgo_search_empty_query",
            query=input_data.query,
        )
        raise ValueError("搜索查询不能为空")
    # ... 继续执行搜索
```

**Tavily API 搜索工具**（`app/tools/search/tavily_api_search.py`）:
```python
async def execute(self, input_data: SearchQuery) -> SearchResult:
    # ✅ 添加查询验证
    if not input_data.query or not input_data.query.strip():
        logger.error(
            "tavily_api_search_empty_query",
            query=input_data.query,
        )
        raise ValueError("搜索查询不能为空")
    # ... 继续执行搜索
```

---

### 2. Agent 层面添加前置验证

**TutorialGeneratorAgent**（`app/agents/tutorial_generator.py`）:
```python
# 处理 web_search 工具调用
if tool_name == "web_search":
    try:
        # ✅ 验证查询参数
        query_text = tool_args.get("query", "").strip()
        if not query_text:
            logger.warning(
                "tool_call_invalid_query",
                tool_name=tool_name,
                tool_args=tool_args,
                message="LLM 传递的 query 参数为空，跳过此工具调用"
            )
            tool_messages.append({
                "role": "tool",
                "tool_call_id": tool_call_id,
                "content": "错误：搜索查询不能为空，请提供有效的搜索关键词"
            })
            continue
        
        # 构建搜索查询
        search_query = SearchQuery(
            query=query_text,
            max_results=tool_args.get("max_results", 5),
        )
        # ... 执行搜索
```

## 修复效果

### 修复前
- ❌ LLM 传递空查询 → 搜索引擎崩溃 → 内部错误日志
- ❌ 无用户友好的错误信息

### 修复后
- ✅ 搜索工具层面拦截空查询，抛出 `ValueError`
- ✅ Agent 层面验证参数，返回友好错误消息给 LLM
- ✅ LLM 可以根据错误信息调整查询并重试
- ✅ 避免内部引擎错误日志污染

---

## 需要同步修复的 Agent

以下 Agent 也使用了 `web_search` 工具，需要同步添加参数验证：

- `ResourceRecommenderAgent` (`app/agents/resource_recommender.py`)
- `ResourceModifierAgent` (`app/agents/resource_modifier.py`)
- `QAAgent` (`app/agents/qa_agent.py`)

**建议统一修复模式**：
1. 验证 `query_text = tool_args.get("query", "").strip()`
2. 如果为空，返回友好错误消息，不执行搜索
3. 记录警告日志，便于监控 LLM 工具调用质量
