## 问题概览

路线图生成流程可以正常完成，但**内容生成阶段数据未保存到数据库**，导致：
- ✅ 教程内容成功生成并上传到 S3
- ❌ 数据库 `tutorials` 表为空
- ❌ 前端无法查询和展示教程内容

## 根因分析（通过终端日志）

### 🔴 问题1：数据库连接池混用（Critical）

**错误日志**（多处出现）：
```python
IllegalStateChangeError: Method 'close()' can't be called here; 
method '_connection_for_bind()' is already in progress
```

**错误链路**：
```
Celery Worker (prefork 模式)
  ↓
TutorialGeneratorAgent (生成教程)
  ↓
web_search 工具调用
  ↓
WebSearchRouter.execute(db_session=None)  ← 未传递 session
  ↓
get_db_transaction()  ❌ 错误：FastAPI 连接池
  ↓
TavilyAPISearchTool
  ↓
IllegalStateChangeError (连接池状态冲突)
```

**架构问题**：
- **Celery Worker** 使用 `NullPool`（无连接池，每次新建连接）
- **FastAPI** 使用 `QueuePool`（连接池复用）
- Celery 的 `prefork` 模式下，子进程继承父进程的连接池引用会导致状态混乱

---

## 修复方案

### ✅ 修复1：WebSearchRouter 环境智能检测

**文件**：`backend/app/tools/search/web_search_router.py`

**核心逻辑**：
```python
if db_session is None:
    # 检测运行环境
    try:
        from celery import current_task
        is_celery = current_task is not None and hasattr(current_task, 'request')
    except (ImportError, AttributeError):
        is_celery = False
    
    if is_celery:
        # ✅ Celery 环境：使用 get_celery_session()
        from app.db.celery_session import get_celery_session
        async with get_celery_session() as session:
            # 在 session 生命周期内完成所有数据库操作
            tavily_available = await self._has_valid_tavily_keys(session)
            if tavily_available:
                tavily_tool = TavilyAPISearchTool(db_session=session)
                return await tavily_tool.execute(input_data)
        
        # session 已关闭，回退到 DuckDuckGo
        if self.duckduckgo_tool:
            return await self.duckduckgo_tool.execute(input_data)
    else:
        # ✅ FastAPI 环境：使用 get_db_transaction()
        from app.db.session import get_db_transaction
        async for session in get_db_transaction():
            db_session = session
            break
```

**关键改进**：
- 检测 Celery 环境：通过 `current_task` 判断
- 使用正确的连接池：Celery → `get_celery_session()`，FastAPI → `get_db_transaction()`
- 生命周期管理：在 `async with` 内完成所有数据库操作

## 架构改进总结

### 连接池隔离设计

| 层级 | FastAPI 环境 | Celery 环境 |
|------|------------|------------|
| **连接池类型** | QueuePool（池化） | NullPool（无池化） |
| **Session 工厂** | `get_db_transaction()` | `get_celery_session()` |
| **使用场景** | API 请求处理 | 异步任务执行 |
| **生命周期** | 请求作用域 | 任务作用域 |

### 数据保存流程

```
WorkflowExecutor.execute()
  ↓
Stream Loop 监听节点完成
  ↓
async with get_celery_session() as session:  ← ✅ Celery 专用 session
    ↓
    HandlerRegistry.handle(session=session)  ← ✅ 传递正确 session
      ↓
      ContentHandler._handle_output(session)  ← ✅ 使用正确 session
        ↓
        tutorial_crud.save_tutorials_batch(session)  ← ✅ 保存到数据库
```
