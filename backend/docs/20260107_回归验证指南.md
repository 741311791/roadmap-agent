## 🐛 常见问题排查

### 问题1: 响应格式不正确

**症状**: 前端获取不到数据，或报TypeError

**排查**:
```bash
# 直接调用API查看响应
curl -X GET http://localhost:8000/api/v1/roadmaps/xxx/concepts/yyy/tutorials

# 检查是否有 code, msg, data 三个字段
# 检查 data 字段是否包含实际数据
```

**解决**: 检查端点是否使用了 `response_base.success(data=...)`

---

### 问题2: 权限验证失败

**症状**: 删除路线图时报403 Forbidden

**排查**:
```bash
# 检查JWT Token是否正确
curl -X DELETE http://localhost:8000/api/v1/roadmaps/roadmap-123 \
  -H "Authorization: Bearer $TOKEN" \
  -v

# 查看请求头是否包含Authorization
# 查看响应是否包含错误详情
```

**解决**: 
- 确保JWT Token有效
- 确保路线图属于当前用户
- 检查user_id是否从JWT正确提取

---

### 问题3: 自动commit未生效

**症状**: 数据库中没有记录，但API返回成功

**排查**:
```python
# 检查端点是否使用了 CurrentSessionTransaction
async def xxx(
    db: CurrentSessionTransaction,  # ✅ 正确
    # db: CurrentSession,  # ❌ 错误（只读）
):
    ...
```

**解决**: 写操作必须使用 `CurrentSessionTransaction`
