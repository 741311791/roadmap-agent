### 2. CRUD层设计

#### BaseCRUD泛型类

**核心方法**:
```python
class BaseCRUD(Generic[ModelType, CreateSchemaType, UpdateSchemaType]):
    - get(session, id) → Optional[ModelType]
    - get_multi(session, skip, limit) → list[ModelType]
    - count(session) → int
    - create(session, obj_in) → ModelType
    - update(session, db_obj, obj_in) → ModelType
    - remove(session, id) → Optional[ModelType]
    - soft_delete(session, id) → Optional[ModelType]
```

### 3. Session读写分离

#### 实现方案

**只读Session** (`get_db_readonly()`):
```python
async def get_db_readonly() -> AsyncGenerator[AsyncSession, None]:
    """
    使用场景：
    - GET请求
    - 查询操作
    - 不需要事务的场景
    """
    async with safe_session() as session:
        yield session
        # ✅ 不commit，避免不必要的开销
```

**写Session** (`get_db_transaction()`):
```python
async def get_db_transaction() -> AsyncGenerator[AsyncSession, None]:
    """
    使用场景：
    - POST/PUT/DELETE请求
    - 需要修改数据的操作
    """
    async with safe_session() as session:
        try:
            yield session
            await session.commit()  # ✅ 成功时自动commit
        except Exception:
            await session.rollback()  # ✅ 异常时自动rollback
            raise
```

#### 类型别名

```python
# 只读Session
CurrentSession = Annotated[AsyncSession, Depends(get_db_readonly)]

# 写Session（事务）
CurrentSessionTransaction = Annotated[AsyncSession, Depends(get_db_transaction)]
```

#### 优势

- **性能提升**: 读操作不再执行无意义的commit
- **明确语义**: 代码可读性提升，一眼看出读写意图
- **错误预防**: 编译期类型检查，避免误用

### 4. 统一依赖注入规范

#### 依赖注入中心（`app/api/v1/deps.py`）

**Session依赖**:
```python
CurrentSession = Annotated[AsyncSession, Depends(get_db_readonly)]

```

**CRUD依赖**:
```python
CurrentRoadmapCRUD = Annotated[RoadmapCRUD, Depends(get_roadmap_crud)]
CurrentTutorialCRUD = Annotated[TutorialCRUD, Depends(get_tutorial_crud)]
# ... 8个CRUD依赖
```

**鉴权依赖**:
```python
CurrentUser = Annotated[User, Depends(get_current_user)]
CurrentActiveUser = Annotated[User, Depends(get_current_active_user)]
```

**权限检查依赖**:
```python
class PermissionChecker:
    """可复用的权限检查器"""
    def __init__(self, required_permission: str):
        self.required_permission = required_permission
    
    def __call__(self, current_user: CurrentUser) -> User:
        # 检查权限逻辑
        ...

RequireAdmin = Annotated[User, Depends(PermissionChecker("admin"))]
```

#### 使用示例

```python
from app.api.v1.deps import (
    CurrentSession,
    CurrentRoadmapCRUD,
    CurrentActiveUser,
)

@router.get("/{roadmap_id}")
async def get_roadmap(
    roadmap_id: str,
    crud: CurrentRoadmapCRUD,
    session: CurrentSession,
    user: CurrentActiveUser,
):
    """获取路线图详情"""
    return await crud.get_by_roadmap_id(session, roadmap_id)
```

## 📝 经验总结

### 成功因素

1. **渐进式设计**: 纯新增代码，零风险
2. **充分文档**: Checklist + 迁移指南，降低学习成本
3. **完整示例**: 所有规范都有代码示例
4. **类型安全**: 泛型约束，编译期检查

### 注意事项

1. **BaseCRUD的局限性**: 
   - 复杂查询仍需自定义方法
   - 关联查询需要显式使用`selectinload`

2. **Session使用规范**:
   - 确保读操作使用`CurrentSession`
   - 确保写操作使用`CurrentSessionTransaction`
   - 避免手动调用`commit()`

3. **依赖注入陷阱**:
   - 避免循环依赖
   - 注意工厂函数的单例性

## 🎓 知识沉淀

### 核心概念

1. **泛型CRUD**: 通过泛型约束实现类型安全的数据访问层
2. **读写分离**: 明确事务边界，提升性能
3. **依赖注入中心**: 统一管理所有依赖，提升可维护性
4. **Schema-First设计**: API设计优先，自动生成文档

### 设计模式

1. **泛型工厂模式**: `BaseCRUD[ModelType, CreateSchemaType, UpdateSchemaType]`
2. **依赖注入模式**: `Annotated[Type, Depends(factory)]`
3. **策略模式**: `PermissionChecker(permission)`

### FastAPI最佳实践

1. 使用`Annotated`简化依赖注入
2. 使用Pydantic v2 `model_config`
3. 使用`Field`添加验证和文档
4. 使用泛型提升代码复用
