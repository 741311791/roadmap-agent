# 任务创建后 Celery Worker 找不到任务修复

**问题**: 路线图生成任务创建后，Celery Worker 报错 "Task not found in database after X retries"  
**状态**: ✅ 已修复

---

## 📋 问题描述

用户创建路线图生成任务后，Celery Worker 在启动时无法在数据库中找到刚创建的任务记录，即使任务记录确实存在于数据库中。

**错误信息**:
```
Task be3b19a0-ffea-47ce-b747-76fd57796750 not found in database after 5 retries
```

**关键观察**:
- 任务记录**确实存在**于数据库中（通过直接查询验证）
- Celery Worker 在 5 次重试后仍然找不到
- 问题反复出现，不是偶发

---

## 🔍 根因分析

### 1. `repo_factory.create_session()` 实现问题

原实现使用 `async for session in get_db()` 来获取 session：

```python
@asynccontextmanager
async def create_session(self):
    async for session in get_db():
        try:
            yield session
        finally:
            pass
```

这种实现虽然能工作，但在与 `get_db()` 生成器交互时，事务边界不够清晰。

### 2. 事务提交与任务分发时序问题

在 `generation.py` 中：
1. 创建任务并 commit
2. 立即分发 Celery 任务
3. Celery Worker 开始执行，查询任务

问题在于：虽然 commit 被调用，但在高并发或数据库连接池复用的情况下，刚提交的数据可能在另一个连接中短暂不可见。

### 3. 重试机制不够健壮

原重试逻辑：
- 最多 5 次重试
- 等待时间：100ms, 200ms, 300ms, 400ms（总计约 1 秒）

这个等待时间在某些情况下可能不够。

---

## ✅ 修复方案

### 1. 重构 `repo_factory.create_session()`

改用 `safe_session_with_retry()` 直接管理 session，避免生成器交互：

```python
@asynccontextmanager
async def create_session(self):
    from app.db.session import safe_session_with_retry
    
    async with safe_session_with_retry() as session:
        yield session
```

### 2. 在分发 Celery 任务前验证持久化

在 `generation.py` 中增加验证步骤：

```python
# 第一步：创建任务并 commit
async with repo_factory.create_session() as session:
    await task_repo.create_task(...)
    await session.commit()

# 第二步：验证任务已持久化（使用新的 session）
max_verify_retries = 5
for attempt in range(max_verify_retries):
    async with repo_factory.create_session() as session:
        task = await task_repo.get_by_task_id(task_id)
        if task:
            break
    await asyncio.sleep(0.05 * (attempt + 1))

if not task:
    raise HTTPException(500, "任务创建失败：数据库持久化验证失败")

# 第三步：分发 Celery 任务（此时任务已确认存在）
celery_task = generate_roadmap.delay(...)
```

### 3. 增强 Celery Worker 重试机制

```python
max_retries = 10  # 5 → 10
for attempt in range(max_retries):
    # ...查询任务...
    if not task:
        base_wait = 0.2 * (attempt + 1)  # 200ms 起步（原 100ms）
        jitter = random.uniform(0, 0.1)  # 随机抖动
        await asyncio.sleep(base_wait + jitter)
```
