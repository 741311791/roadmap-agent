# 约束系统 Bug 修复说明

## 修复概述

在用户画像约束系统实施过程中，发现并修复了 2 个关键 Bug，确保系统正确处理新格式的 `full_analysis_data`（约束文本字典）。

## Bug 1：CRUD 层保存错误

### 问题描述

**文件**: `backend/app/crud/crud_intent_analysis.py:73`

**错误代码**：
```python
full_analysis_data=intent_analysis.model_dump(),  # ❌ 错误
```

**问题**：
- 使用 `model_dump()` 保存完整对象，而不是约束文本字典
- 导致数据库中保存的是旧格式（完整的 IntentAnalysisOutput 对象）
- 其他 Agent 无法正确读取约束

### 修复方案

**修复后代码**：
```python
# ✅ 修复：直接使用约束文本字典，而不是完整对象
full_analysis_data=intent_analysis.full_analysis_data,
```

**修复说明**：
- 直接使用 `intent_analysis.full_analysis_data`（已由 IntentAnalyzerAgent 生成）
- 保存的是约束文本字典格式：`{"约束名称": "约束内容"}`
- 符合新的数据格式规范

### 影响范围

**修复前**：
- 数据库中保存的是旧格式（完整对象）
- 其他 Agent 读取约束时会失败
- 缓存机制无法正常工作

**修复后**：
- 数据库中保存约束文本字典
- 其他 Agent 可以正确读取和过滤约束
- 缓存机制正常工作

## Bug 2：内容生成任务使用错误

### 问题描述

**文件**: `backend/app/tasks/content_generation_tasks.py:367-376`

**错误代码**：
```python
if intent_analysis and intent_analysis.full_analysis_data:
    # 从 intent_analysis 提取用户偏好
    analysis_data = intent_analysis.full_analysis_data
    user_preferences = LearningPreferences(
        learning_goal=analysis_data.get("learning_goal", "学习目标"),  # ❌ 错误
        available_hours_per_week=analysis_data.get("available_hours_per_week", 10),
        motivation=analysis_data.get("motivation", "学习"),
        current_level=analysis_data.get("current_level", "beginner"),
        career_background=analysis_data.get("career_background", "默认背景"),
    )
```

**问题**：
- 尝试从 `full_analysis_data` 中提取 `learning_goal`、`available_hours_per_week` 等字段
- 但新格式的 `full_analysis_data` 是约束文本字典，不包含这些原始字段
- 会导致构建 `LearningPreferences` 失败

### 修复方案

**修复后代码**：
```python
if intent_analysis:
    # ✅ 修复：从 IntentAnalysisMetadata 的字段中提取数据
    # 注意：原始用户输入（learning_goal 等）未保存到数据库
    # 使用分析结果字段构建 LearningPreferences
    
    # 从 difficulty_profile 中推断 current_level
    current_level = "beginner"
    if intent_analysis.difficulty_profile:
        if "advanced" in intent_analysis.difficulty_profile.lower():
            current_level = "advanced"
        elif "intermediate" in intent_analysis.difficulty_profile.lower():
            current_level = "intermediate"
    
    # 从 language_preferences 中获取主要语言
    primary_language = "zh"
    if intent_analysis.language_preferences:
        primary_language = intent_analysis.language_preferences.get("primary_language", "zh")
    
    user_preferences = LearningPreferences(
        learning_goal=intent_analysis.parsed_goal,  # 使用结构化的学习目标
        available_hours_per_week=10,  # 默认值（原始值未保存）
        motivation="学习",  # 默认值
        current_level=current_level,  # 从 difficulty_profile 推断
        career_background=intent_analysis.user_profile_summary or "默认背景",
        primary_language=primary_language,
    )
```

**修复说明**：
- 改为从 `IntentAnalysisMetadata` 的直接字段中提取数据
- 使用 `parsed_goal` 而不是原始的 `learning_goal`
- 从 `difficulty_profile` 推断 `current_level`
- 使用 `user_profile_summary` 作为 `career_background`
- 对于未保存的原始字段使用合理的默认值

### 影响范围

**修复前**：
- 内容生成任务会因为无法构建 `LearningPreferences` 而失败
- 获取到的字段都是默认值（因为 `analysis_data.get()` 返回默认值）

**修复后**：
- 正确从分析结果字段中提取数据
- 构建的 `LearningPreferences` 包含有意义的值
- 内容生成任务可以正常工作
