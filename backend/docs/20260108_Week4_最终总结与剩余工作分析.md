## ⚠️ 核心挑战分析

### 挑战1: CeleryRepositoryFactory（最复杂）

**问题描述**:
```python
# app/db/celery_session.py
class CeleryRepositoryFactory:
    """Celery专用Repository工厂，解决Fork进程Session问题"""
    
    def create_roadmap_repo(self, session):
        from app.db.repositories.roadmap_repo import RoadmapRepository
        return RoadmapRepository(session)
    
    # ... 共9个create_xxx_repo方法
```

**影响范围**:
- celery_session.py（核心文件，所有Celery任务依赖）
- content_generation_tasks.py
- content_retry_tasks.py
- concept_generator.py

**迁移方案**:
```python
# ✅ 方案1: 重构为CRUD工厂
class CeleryCRUDFactory:
    """Celery专用CRUD工厂"""
    
    @staticmethod
    def get_roadmap_crud():
        from app.crud.crud_roadmap import get_roadmap_crud
        return get_roadmap_crud()
    
    # ... 改用CRUD的get函数

# ✅ 方案2: 直接使用CRUD单例
# 在Celery任务中直接导入CRUD
from app.crud import get_roadmap_crud, get_task_crud
```

**推荐**: 方案2（直接使用CRUD单例，更简洁）
