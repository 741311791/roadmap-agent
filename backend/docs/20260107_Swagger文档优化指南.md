## ✅ 已优化的Schema示例

### 1. 包含详细描述和示例

```python
# backend/app/schemas/content.py

class TutorialItemResponse(BaseModel):
    """教程项响应"""
    tutorial_id: str = Field(..., description="教程ID")
    title: str = Field(..., description="教程标题")
    summary: Optional[str] = Field(None, description="教程摘要")
    content_url: Optional[str] = Field(None, description="内容URL（S3）")
    content_version: int = Field(..., description="内容版本号")
    is_latest: bool = Field(..., description="是否为最新版本")
    content_status: str = Field(..., description="内容生成状态")
    generated_at: Optional[str] = Field(None, description="生成时间（ISO格式）")
    
    model_config = {
        "json_schema_extra": {
            "examples": [
                {
                    "tutorial_id": "tutorial-123",
                    "title": "Python基础入门",
                    "summary": "本教程介绍Python的基本语法",
                    "content_url": "s3://bucket/tutorials/123.md",
                    "content_version": 1,
                    "is_latest": True,
                    "content_status": "completed",
                    "generated_at": "2026-01-07T10:00:00Z"
                }
            ]
        }
    }
```

**Swagger效果**:
- ✅ 每个字段都有中文描述
- ✅ 自动显示示例数据
- ✅ 自动显示必填/可选标记

### 1. 端点级别的详细描述

```python
@router.post(
    "/generate",
    response_model=ResponseSchemaModel[GenerateRoadmapResponse],
    summary="生成学习路线图",  # ✅ 简短摘要（显示在列表）
    description="""
    将任务分发到 Celery Worker 执行，FastAPI 进程立即返回。
    
    **流程说明**:
    1. 创建任务记录
    2. 验证任务持久化
    3. 分发Celery任务
    4. 返回任务ID
    
    **注意事项**:
    - 任务ID可用于WebSocket订阅进度
    - roadmap_id将在需求分析完成后通过WebSocket发送
    """,  # ✅ 详细描述（显示在详情页）
    responses={
        200: {
            "description": "任务创建成功",

## 🎯 优化建议

### 1. 添加全局说明

在 `main.py` 中补充API文档的全局说明：

```python
app = FastAPI(
    title="Learning Roadmap Generation System",
    description="""
    ## 🎓 学习路线图生成系统 API
    
    基于 Multi-Agent 的个性化学习路线图生成系统后端接口。
    
    ### 🔐 认证方式
    
    大部分端点需要JWT Token认证：
    ```
    Authorization: Bearer <your-jwt-token>
    ```
    
    ### 📦 统一响应格式
    
    所有成功响应：
    ```json
    {
      "code": 200,
      "msg": "Success",
      "data": { ... }
    }
    ```
    
    所有错误响应：
    ```json
    {
      "error": {
        "code": "NOT_FOUND",
        "message": "资源不存在",
        "request_id": "req-123"
      }
    }
    ```
    
    ### 🏷️ 错误码说明
    
    - `NOT_FOUND` - 资源不存在
    - `BAD_REQUEST` - 请求参数错误
    - `UNAUTHORIZED` - 未授权访问
    - `FORBIDDEN` - 权限不足
    - `VALIDATION_ERROR` - 数据验证失败
    - `INTERNAL_SERVER_ERROR` - 服务器内部错误
    
    ### 📡 实时通信
    
    路线图生成进度通过WebSocket推送：
    ```
    ws://localhost:8000/api/v1/ws/{task_id}
    ```
    """,
    version="1.0.0",
    lifespan=lifespan,
    docs_url="/docs",
    redoc_url="/redoc",
    openapi_url="/openapi.json",
)
```
