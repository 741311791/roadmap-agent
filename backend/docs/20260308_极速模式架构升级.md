# 极速模式（Turbo Mode）架构升级

## 需求背景

原工作流主路节点为：`IntentAnalysis → CurriculumDesign → StructureValidation → HumanReview → Content`。结构验证（StructureValidation）引入额外等待时间，影响用户体验。极速模式允许跳过该节点，CurriculumDesign 后直接进入 HumanReview。

---

## 核心变更

### 后端（5 个文件）

#### 1. `UserRequest` 新增字段（`backend/app/models/domain.py`）
```python
turbo_mode: bool = Field(True, description="极速模式：跳过结构验证节点")
```
默认值 `True`，表示新任务默认开启极速模式。

#### 2. 新增路由函数（`backend/app/core/orchestrator/routers.py`）
```python
def route_after_curriculum(self, state: RoadmapState) -> str
```
- `turbo_mode=True`：直接返回 `"human_review"`（或 `"end"`）
- `turbo_mode=False`：返回 `"structure_validation"`，走原有验证路径

#### 3. 工作流边改造（`backend/app/core/orchestrator/builder.py`）

| 改造前 | 改造后 |
|---|---|
| `curriculum_design → structure_validation`（固定边） | `curriculum_design → route_after_curriculum`（条件边） |

条件边映射：
```python
{
    "structure_validation": "structure_validation",
    "human_review": "human_review" if not skip_human_review else END,
    "end": END,
}
```

#### 4. 任务状态响应透出（`backend/app/schemas/task.py`）
`TaskStatusDetailResponse` 新增：
```python
turbo_mode: Optional[bool] = Field(None, description="是否为极速模式")
```

#### 5. 状态读取（`backend/app/services/roadmaps/roadmap_service.py`）
```python
turbo_mode = user_request_data.get("turbo_mode", True)
```
从 `task.user_request` JSON 中读取并填入响应，默认 `True`（兼容历史数据）。

---

### 前端（5 个文件）

#### 1. 类型定义（`frontend-next/types/generated/models/UserRequest.ts`）
```typescript
turbo_mode?: boolean;  // 极速模式
```

#### 2. 任务状态类型（`frontend-next/types/generated/models/TaskStatusDetailResponse.ts`）
```typescript
turbo_mode?: (boolean | null);
```

#### 3. 创建表单（`frontend-next/app/(app)/new/new-roadmap-client.tsx`）
- `FormData` 新增 `turboMode: boolean`，初始化默认 `true`
- preferences 步骤中插入 Turbo Mode 开关卡片（使用主题色 `sage`，支持中英文 i18n）
- 提交时传递 `turbo_mode: formData.turboMode`

#### 4. i18n 词条（`messages/en.json` / `messages/zh.json`）
| Key | EN | ZH |
|---|---|---|
| `turboMode` | Turbo Mode | 极速模式 |
| `turboModeOn` | ON | 开启 |
| `turboModeDesc` | Skip structure validation... | 跳过结构验证... |

#### 5. 工作流进度组件（`frontend-next/components/task/workflow-topology.tsx`）
- 新增 `turboMode?: boolean` prop（默认 `true`）
- 极速模式下过滤掉 `validate`（StructureValidation）节点，避免前端显示未执行的节点

任务详情页（`page.tsx`）透传：
```typescript
turboMode={taskInfo.turbo_mode ?? true}
```
`?? true` 确保历史任务（无此字段）默认隐藏 validate 节点。

---

## 工作流路径对比

```
极速模式（turbo_mode=true）：
  IntentAnalysis → CurriculumDesign → HumanReview → END

普通模式（turbo_mode=false）：
  IntentAnalysis → CurriculumDesign → StructureValidation → [验证循环] → HumanReview → END
```

---

## 兼容性说明

- 历史任务：`user_request` JSON 中无 `turbo_mode` 字段，后端读取时默认 `True`，前端也默认隐藏验证节点
- `UserRequest.turbo_mode` 存于 `roadmap_tasks.user_request` JSON 列，无需 DB 迁移
