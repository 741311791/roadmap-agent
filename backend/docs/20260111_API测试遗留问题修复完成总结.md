### 问题4: OrchestratorFactory未初始化 ✅

**问题描述**: 某些API端点依赖WorkflowExecutor，需要初始化OrchestratorFactory

**错误信息**:
```
RuntimeError: OrchestratorFactory 未初始化，请先调用 initialize()
```

**根本原因**: 
- status查询、cancel等端点需要WorkflowExecutor
- 之前的session scope fixture与function scope事件循环冲突

**修复文件**: `tests/conftest.py`

**修复内容**:
```python
@pytest.fixture
async def initialized_orchestrator():
    """
    为需要OrchestratorFactory的测试初始化
    
    使用function scope避免与事件循环冲突。
    """
    from app.core.orchestrator_factory import OrchestratorFactory
    
    try:
        if not OrchestratorFactory._initialized:
            await OrchestratorFactory.initialize()
        yield
    except Exception as e:
        import warnings
        warnings.warn(f"OrchestratorFactory initialization failed: {e}")
        yield
```

**影响**: 
- 所有依赖WorkflowExecutor的测试需要添加`initialized_orchestrator` fixture
- 修复了6个ERROR级测试

## 五、关键修复详解

### 5.1 OrchestratorFactory初始化策略

**问题**: session scope fixture与function scope事件循环不兼容

**解决方案**: 改用function scope的按需初始化

```python
@pytest.fixture
async def initialized_orchestrator():
    """按需初始化，避免scope冲突"""
    from app.core.orchestrator_factory import OrchestratorFactory
    
    if not OrchestratorFactory._initialized:
        await OrchestratorFactory.initialize()
    yield
```

**使用方式**:
```python
@pytest.mark.asyncio
async def test_get_task_status_not_found(
    self,
    client: AsyncClient,
    auth_headers: dict,
    initialized_orchestrator  # 添加此fixture
):
    ...
```

**效果**: 
- 解决了ScopeMismatch错误
- 需要WorkflowExecutor的测试可以正常运行
- 不影响不需要orchestrator的测试

## 六、剩余问题分析

### 🔴 P0 - 事件循环管理（系统性问题）

**影响**: 27个ERROR级测试

**表现**:
```
RuntimeError: Event loop is closed
sqlalchemy.pool.impl.AsyncAdaptedQueuePool: Exception terminating connection
```

**根本原因**:
1. pytest-asyncio在测试结束时关闭事件循环
2. SQLAlchemy AsyncEngine的连接池清理需要活跃的事件循环
3. 清理顺序：事件循环先关闭 → 连接池无法异步清理

**不是测试代码的问题**: 
- 这是pytest-asyncio + SQLAlchemy的已知兼容性问题
- 影响所有使用`test_session` fixture的测试
- 需要系统性的架构改进

**建议解决方案**:
1. 实施TestDatabaseManager（专用数据库管理器）
2. 使用pytest-asyncio的`asyncio_mode = "strict"`
3. 手动管理连接池生命周期
