## 八、架构亮点

### 亮点 1：三层约束架构

```
Layer 1: 约束生成层（IntentAnalyzerAgent）
  ↓ 从用户画像生成 12 个约束
Layer 2: 约束管理层（BaseAgent + RuntimeContext）
  ↓ 过滤、缓存、加载
Layer 3: 约束应用层（各 Agent + Prompt）
  ↓ 注入到 Prompt，驱动个性化生成
```

### 亮点 2：智能约束过滤

```
12 个完整约束
  ↓ _get_required_constraints()
定义需求
  ↓ _filter_constraints()
3-11 个过滤后的约束
  ↓ 传递给 Prompt
个性化生成
```

### 亮点 3：多级缓存策略

```
请求约束
  ↓ 优先级 1
内存传递（intent_analysis）
  ↓ 优先级 2
RuntimeContext 缓存
  ↓ 优先级 3
数据库查询
  ↓ 优先级 4
空字典（降级）
```
