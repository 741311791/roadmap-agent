# 枚举常量使用规范修复

## 问题描述

### 违规代码

在 `workflow_execution_service.py` 中，多处使用了**字符串字面量**而不是**枚举常量**，违反了开发规范。

**违规示例**：
```python
# ❌ 错误：使用字符串字面量
current_step = final_state.get("current_step", "completed")
if current_step == "human_review":
    ...
elif current_step == "structure_validation":
    ...
elif current_step == "completed":
    ...
```

### 规范要求

根据 `backend/app/models/constants.py` 中定义的 `WorkflowStep` 枚举：

```python
class WorkflowStep(str, Enum):
    """工作流步骤枚举"""
    INTENT_ANALYSIS = "intent_analysis"
    CURRICULUM_DESIGN = "curriculum_design"
    STRUCTURE_VALIDATION = "structure_validation"
    HUMAN_REVIEW = "human_review"
    EDIT_PLAN_ANALYSIS = "edit_plan_analysis"
    ROADMAP_EDIT = "roadmap_edit"
    CONTENT_GENERATION_QUEUED = "content_generation_queued"
    CONTENT_GENERATION = "content_generation"
    COMPLETED = "completed"
    FAILED = "failed"
```

**必须使用枚举常量**：
```python
# ✅ 正确：使用枚举常量
from app.models.constants import WorkflowStep

current_step = final_state.get("current_step", WorkflowStep.COMPLETED.value)
if current_step == WorkflowStep.HUMAN_REVIEW.value:
    ...
elif current_step == WorkflowStep.STRUCTURE_VALIDATION.value:
    ...
elif current_step == WorkflowStep.COMPLETED.value:
    ...
```

## 规范总结

### ❌ 禁止做法

1. **禁止使用字符串字面量**：
   ```python
   # ❌ 错误
   if current_step == "human_review":
       ...
   
   task.current_step = "completed"
   
   status = "processing"
   ```

2. **禁止自创枚举值**：
   ```python
   # ❌ 错误（WorkflowStep 中不存在 REVIEW）
   current_step = "review"
   ```

3. **禁止混用字符串和枚举**：
   ```python
   # ❌ 错误（一会儿用枚举，一会儿用字符串）
   if current_step == WorkflowStep.COMPLETED.value:
       task.current_step = "completed"  # 应该用枚举
   ```

### ✅ 正确做法

1. **严格使用枚举常量**：
   ```python
   # ✅ 正确
   from app.models.constants import WorkflowStep, TaskStatus
   
   if current_step == WorkflowStep.HUMAN_REVIEW.value:
       task.status = TaskStatus.HUMAN_REVIEW.value
   ```

2. **默认值也使用枚举**：
   ```python
   # ✅ 正确
   current_step = final_state.get("current_step", WorkflowStep.COMPLETED.value)
   ```

3. **完全一致性**：
   ```python
   # ✅ 正确（整个代码库保持一致）
   if current_step == WorkflowStep.COMPLETED.value:
       task.current_step = WorkflowStep.COMPLETED.value
       task.status = TaskStatus.COMPLETED.value
   ```
