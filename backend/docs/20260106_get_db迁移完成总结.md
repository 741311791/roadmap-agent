## 🔧 技术细节

### 迁移模式

#### 模式1：简单替换（大多数情况）

**旧代码**:
```python
from app.db.session import get_db

async def endpoint(db: AsyncSession = Depends(get_db)):
    ...
```

**新代码（读操作）**:
```python
from app.db.session import get_db_readonly

async def endpoint(db: AsyncSession = Depends(get_db_readonly)):
    ...
```

**新代码（写操作）**:
```python
from app.db.session import get_db_transaction

async def endpoint(db: AsyncSession = Depends(get_db_transaction)):
    ...
```

#### 模式2：局部导入（特殊情况）

在`tech_assessment.py`中有一处函数内部导入：

```python
# 旧代码
from app.db.session import get_db

# 新代码（使用别名保持兼容）
from app.db.session import get_db_transaction as get_db
```

### 读写分离策略

| HTTP方法 | Session类型 | 原因 |
|---------|-------------|------|
| GET | `get_db_readonly()` | 纯查询，不需要commit |
| POST | `get_db_transaction()` | 创建数据，需要事务 |
| PUT/PATCH | `get_db_transaction()` | 更新数据，需要事务 |
| DELETE | `get_db_transaction()` | 删除数据，需要事务 |

**特殊情况**：
- **认证模块**使用`get_db_transaction()`，因为可能更新`last_login`字段
- **搜索工具**使用`get_db_transaction()`，因为可能记录搜索历史

## 📝 保留的`get_db()`函数

为了渐进式迁移，暂时保留了`get_db()`作为`get_db_transaction()`的别名：

```python
async def get_db() -> AsyncGenerator[AsyncSession, None]:
    """
    ⚠️ 已废弃：请使用 get_db_readonly() 或 get_db_transaction()
    """
    async for session in get_db_transaction():
        yield session
```

**状态**：
- 所有直接引用已迁移完成
- 保留作为过渡，防止遗漏的动态引用
- 计划在确认无影响后删除
