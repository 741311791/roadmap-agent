## 🎯 关键修复详情

### 1. WebSocket鉴权实现

**文件**: `backend/app/api/v1/websocket.py`

**改动**:
- 添加JWT Token验证（通过Query参数传递）
- 验证Token有效性和过期时间
- 检查用户是否拥有任务访问权限
- 拒绝未授权连接

**安全增强**:
```python
# 旧版：无任何鉴权
@router.websocket("/ws/{task_id}")
async def websocket_endpoint(websocket: WebSocket, task_id: str):
    await manager.connect(websocket, task_id)  # ❌ 任意用户可订阅

# 新版：完整鉴权流程
@router.websocket("/ws/{task_id}")
async def websocket_endpoint(
    websocket: WebSocket,
    task_id: str,
    token: str = Query(None),  # ✅ 必须提供JWT Token
):
    # 验证Token、检查权限
    if not token or not valid or task.user_id != user_id:
        await websocket.close(code=status.WS_1008_POLICY_VIOLATION)
        return
```

### 2. 中间件顺序修正

**文件**: `backend/app/main.py`

**改动**:
- 调整中间件添加顺序，确保CORS在最外层
- 添加`expose_headers`，允许前端访问`X-Request-ID`
- 增加详细注释说明洋葱圈模型

**执行顺序**:
```
请求流向： Client → [CORS检查] → [生成RequestID] → 路由处理
                    ↑ 外层           ↑ 内层
                 后添加           先添加

响应流向： 路由处理 → [注入RequestID] → [添加CORS头] → Client
```

---

### 3. BackgroundTasks Session修复

**新增文件**: `backend/app/tasks/cover_image_tasks.py`  
**修改文件**: `backend/app/api/v1/endpoints/cover_image.py`

**改动**:
- 创建独立的Celery任务：`generate_cover_image_task`
- 移除所有`BackgroundTasks`依赖
- 使用独立Session，避免泄漏

**架构对比**:
```python
# 旧版：BackgroundTasks + 请求级Session（❌ 泄漏风险）
background_tasks.add_task(
    service.generate_cover_image,
    session=session,  # ❌ 请求结束后session关闭
)

# 新版：Celery + 独立Session（✅ 资源隔离）
celery_task = generate_cover_image_task.delay(
    roadmap_id=roadmap_id,
    prompt=prompt,
)  # ✅ 独立进程，独立Session
```

### 5. JWT黑名单机制

**新增文件**:
- `backend/app/core/auth/jwt_blacklist.py`
- `backend/app/api/v1/endpoints/auth_ext.py`

**修改文件**:
- `backend/app/core/auth/strategies.py`
- `backend/app/api/v1/router.py`

**功能**:
- 生成Token时自动添加`jti`（JWT ID）
- 验证Token时检查Redis黑名单
- 提供`/api/v1/auth/logout`端点
- 支持Token自动过期清理

**使用示例**:
```bash

curl -X POST http://localhost:8000/api/v1/auth/logout \
  -H "Authorization: Bearer eyJ..."

# 响应
{
  "message": "成功登出",
  "user_id": "user-123"
}
```
