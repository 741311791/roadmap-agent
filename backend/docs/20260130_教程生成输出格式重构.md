# 教程生成输出格式重构：从混合格式到纯 JSON

## 问题描述

### 原始错误
在教程内容生成过程中，`TutorialGeneratorAgent` 在解析 LLM 输出时出现 JSON 解析错误：

```
JSONDecodeError: Expecting value: line 1 column 1 (char 0)
```

**错误位置**：`backend/app/agents/tutorial_generator.py:379`（`_parse_output` 方法）

### 根本原因：架构设计问题

**原始设计的致命缺陷**：使用了不合理的"混合输出格式"

```
# 教程标题

[Markdown 内容...]

===TUTORIAL_METADATA===
{
  "title": "...",
  "summary": "...",
  "estimated_completion_time": 90
}
```

**问题分析**：
1. ❌ LLM 难以准确生成这种人为设计的混合格式
2. ❌ 分隔符 `===TUTORIAL_METADATA===` 容易丢失或格式错误
3. ❌ 需要大量容错代码处理各种边界情况
4. ❌ 维护成本高，不符合结构化输出的最佳实践

## 解决方案：重构为纯 JSON 输出

### 核心改进：使用 OpenAI Structured Output

**新设计理念**：
- ✅ 使用 `response_format={"type": "json_object"}` 强制 LLM 返回有效 JSON
- ✅ JSON 包含两个清晰的字段：`markdown_content` 和 `metadata`
- ✅ 消除歧义，降低解析失败率，提高系统可靠性

**新输出格式**：
```json
{
  "markdown_content": "# 教程标题\n\n## 概述\n[完整内容]\n\n## 核心概念\n...",
  "metadata": {
    "title": "教程标题",
    "summary": "简短摘要",
    "estimated_completion_time": 90
  }
}
```

def _create_langchain_llm(self, response_format: Dict | None = None):
    """
    创建 LangChain 兼容的 LLM 实例
    
    Args:
        response_format: 响应格式约束（可选）
            - None: 默认文本格式
            - {"type": "json_object"}: 强制返回 JSON
    """
    llm_kwargs = {
        "model": model_identifier,
        "temperature": self.temperature,
        "max_tokens": self.max_tokens,
    }
    
    # 关键：通过 model_kwargs 传递 response_format
    if response_format:
        llm_kwargs["model_kwargs"] = {"response_format": response_format}
    
    llm = ChatLiteLLM(**llm_kwargs)
    return llm
```

##### 2.2 简化输出解析逻辑

**之前**：复杂的分隔符查找、多层容错、字符串分割...
**之后**：直接解析 JSON，清晰简单

```python
def _parse_output(self, content: str, concept: Concept) -> tuple[str, dict]:
    """
    解析 JSON 格式的输出
    
    期望格式：
    {
        "markdown_content": "完整的 Markdown 教程内容",
        "metadata": { ... }
    }
    """
    try:
        # 去除可能的代码块标记
        json_content = content.strip()
        if json_content.startswith("```json"):
            json_content = json_content[7:]
        if json_content.startswith("```"):
            json_content = json_content[3:]
        if json_content.endswith("```"):
            json_content = json_content[:-3]
        json_content = json_content.strip()
        
        # 直接解析 JSON
        output = json.loads(json_content)
        
        # 提取字段
        tutorial_markdown = output.get("markdown_content", "")
        metadata = output.get("metadata", {})
        
        # 验证和补全必填字段
        if not tutorial_markdown:
            raise ValueError("markdown_content field is empty")
        
        if not metadata:
            metadata = self._create_default_metadata(concept)
        else:
            # 确保包含所有必填字段
            if "title" not in metadata:
                metadata["title"] = concept.name
            if "summary" not in metadata:
                metadata["summary"] = concept.description[:100] if concept.description else ""
            if "estimated_completion_time" not in metadata:
                metadata["estimated_completion_time"] = int(concept.estimated_hours * 60)
        
        logger.info(
            "tutorial_output_parsed",
            concept_id=concept.concept_id,
            format="json",
            markdown_length=len(tutorial_markdown),
        )
        
        return tutorial_markdown, metadata
        
    except (json.JSONDecodeError, ValueError, KeyError) as e:
        # 容错处理：使用默认元数据
        logger.error(
            "tutorial_json_parse_failed",
            concept_id=concept.concept_id,
            error=str(e),
            error_type=type(e).__name__,
            message="Using entire content as markdown with default metadata"
        )
        return content.strip(), self._create_default_metadata(concept)
```

**文件**：`backend/prompts/tutorial_generator_react.j2`

**修改内容**：

```jinja2
## 输出格式（严格遵守 - 纯 JSON 格式）

**重要**：你的输出必须是有效的 JSON 对象，包含以下两个字段：

```json
{
  "markdown_content": "# 教程标题\n\n## 概述\n[完整的 Markdown 教程内容]\n\n## 核心概念\n[内容]\n\n## 实践示例\n[内容]\n\n## 总结\n[内容]",
  "metadata": {
    "title": "教程标题",
    "summary": "不超过100字的简短摘要",
    "estimated_completion_time": 90
  }
}
```

**字段说明**：
- `markdown_content`: 完整的 Markdown 格式教程内容（字符串）
  - 使用 `\n` 表示换行
  - 包含所有章节：概述、核心概念、实践示例、总结等
  - 必须是有效的 Markdown 语法
  
- `metadata`: 教程元数据（对象）
  - `title`: 教程标题（字符串）
  - `summary`: 简短摘要，不超过100字（字符串）
  - `estimated_completion_time`: 预估完成时间，单位分钟（整数）

**注意事项**：
- 输出必须是有效的 JSON 格式（使用双引号，正确转义特殊字符）
- Markdown 内容中的换行使用 `\n`，引号使用 `\"`
- 不要在 JSON 外添加任何其他内容（包括代码块标记 \`\`\`）
- 所有字段都是必填的

## 输出前最后检查

- [ ] 是否生成了完整的 Markdown 教程内容？
- [ ] 是否包含了所有必需的元数据字段（title、summary、estimated_completion_time）？
- [ ] 输出是否是有效的 JSON 格式（使用双引号，正确转义）？
- [ ] Markdown 内容中的换行是否使用了 `\n`？
```

## 未来优化方向

### 1. 使用 JSON Schema（OpenAI Function Calling）

更进一步，可以使用 JSON Schema 定义精确的输出格式：

```python
response_format = {
    "type": "json_schema",
    "json_schema": {
        "name": "tutorial_output",
        "strict": True,
        "schema": {
            "type": "object",
            "properties": {
                "markdown_content": {
                    "type": "string",
                    "description": "完整的 Markdown 教程内容"
                },
                "metadata": {
                    "type": "object",
                    "properties": {
                        "title": {"type": "string"},
                        "summary": {"type": "string"},
                        "estimated_completion_time": {"type": "integer"}
                    },
                    "required": ["title", "summary", "estimated_completion_time"]
                }
            },
            "required": ["markdown_content", "metadata"]
        }
    }
}
```

**优势**：
- 强制字段类型验证
- 自动拒绝不符合 Schema 的输出
- 100% 格式保证

### 2. 增加输出质量验证

```python
def _validate_tutorial_output(self, markdown: str, metadata: dict) -> bool:
    """验证教程输出质量"""
    # 验证 Markdown 长度
    if len(markdown) < 500:
        return False
    
    # 验证必需章节
    required_sections = ["## 概述", "## 核心概念", "## 实践示例", "## 总结"]
    for section in required_sections:
        if section not in markdown:
            return False
    
    # 验证元数据合理性
    if metadata.get("estimated_completion_time", 0) <= 0:
        return False
    
    return True
```

### 3. 添加重试机制

```python
async def generate_with_retry(self, concept, context, user_preferences, max_retries=2):
    """带重试的教程生成"""
    for attempt in range(max_retries + 1):
        try:
            result = await self.generate(concept, context, user_preferences)
            
            # 验证输出质量
            if self._validate_tutorial_output(result.content_url, result):
                return result
            
            logger.warning("tutorial_quality_check_failed", attempt=attempt)
            
        except Exception as e:
            if attempt == max_retries:
                raise
            logger.warning("tutorial_generation_retry", attempt=attempt, error=str(e))
    
    # 最后一次尝试失败，使用降级方案
    return self._generate_fallback_tutorial(concept)
```
