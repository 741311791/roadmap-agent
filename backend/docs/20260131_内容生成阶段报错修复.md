# 内容生成阶段报错修复

**日期**: 2026-01-31  
**状态**: ✅ 已完成

## 问题概述

内容生成阶段出现多个错误，导致 Tutorial 生成失败。主要问题包括：
1. LangChain `create_agent` 返回工具调用列表而非最终教程内容
2. TutorialGeneratorAgent 缺少错误处理
3. context 参数传递不完整
4. Prompt 设计过于简单

## 错误分析

### 1. 核心错误：输出类型错误

```
TypeError: Expected JSON object (dict), but got list. 
Output preview: [{'name': 'resolve-library-id', 'arguments': {...}}]
```

**原因**：
- `create_agent` 的最终消息可能是工具调用列表，而不是文本响应
- 代码直接提取 `result["messages"][-1].content`，未检查消息类型

### 2. 次要错误：参数传递问题

```
'list' object has no attribute 'get'
```

**原因**：
- `content_generation_tasks.py` 传递的 context 是空字典 `{}`
- 缺少必需的 `roadmap_id` 和 `content_version` 字段

## 修复方案

### 1. TutorialGeneratorAgent 输出提取逻辑优化

**文件**：`backend/app/agents/tutorial_generator.py`

**修改前**：
```python
# 直接提取最后一条消息
final_message = result["messages"][-1]
content = final_message.content
```

**修改后**：
```python
# 反向遍历消息列表，找到最后一个包含文本内容的 AI 消息
content = None
for message in reversed(result["messages"]):
    # 检查是否是 AI 消息且包含文本内容
    if hasattr(message, "content") and isinstance(message.content, str) and message.content.strip():
        content = message.content
        break
    # 如果 message 是字典格式
    elif isinstance(message, dict) and message.get("content") and isinstance(message.get("content"), str):
        content = message["content"]
        break

if not content:
    raise ValueError(
        "Agent did not produce any text content. "
        f"Last message type: {type(result['messages'][-1]).__name__ if result['messages'] else 'None'}"
    )
```

**优势**：
- 正确处理 ReAct Agent 的消息流
- 跳过工具调用消息，只提取文本响应
- 提供详细的错误信息便于调试

### 2. JSON 解析增强类型检查

**文件**：`backend/app/agents/tutorial_generator.py`

**修改内容**：
```python
def _parse_output(self, content: str, concept: Concept) -> tuple[str, dict]:
    # 解析 JSON
    output = json.loads(json_content)
    
    # 类型检查：必须是字典
    if not isinstance(output, dict):
        logger.error(
            "tutorial_output_invalid_type",
            concept_id=concept.concept_id,
            expected_type="dict",
            actual_type=type(output).__name__,
            output_preview=str(output)[:200],
        )
        raise TypeError(
            f"Expected JSON object (dict), but got {type(output).__name__}. "
            f"Output preview: {str(output)[:200]}"
        )
    
    # 验证必填字段
    if not tutorial_markdown:
        raise ValueError(
            f"markdown_content field is empty or missing. "
            f"Available keys: {list(output.keys())}"
        )
    
    if not metadata:
        raise ValueError(
            f"metadata field is missing or empty. "
            f"Available keys: {list(output.keys())}"
        )
```

**改进**：
- 严格的类型检查（dict vs list）
- 详细的错误日志（包含实际类型和内容预览）
- 清晰的错误信息（显示可用的键）
