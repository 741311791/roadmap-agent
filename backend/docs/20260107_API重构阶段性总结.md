3. **统一响应格式**:
```python
# ✅ 所有响应遵循标准格式

@router.get("/xxx", response_model=ResponseSchemaModel[XxxResponse])
async def get_xxx() -> ResponseSchemaModel[XxxResponse]:
    data = await service.get_xxx()
    return response_base.success(data=data)
```

## 🚨 Breaking Changes（已实现）

### 响应格式变化

**旧格式**（直接返回数据）:
```json
{
  "users": [...],
  "total": 100
}
```

**新格式**（统一包装）:
```json
{
  "code": 200,
  "msg": "Success",
  "data": {
    "users": [...],
    "total": 100
  }
}
```

**前端适配**:
```typescript
// 旧代码
const data = await response.json();
console.log(data.users);

// 新代码
const result = await response.json();
if (result.code === 200) {
    console.log(result.data.users);
} else {
    console.error(result.msg);
}
```

### 错误码变化

**旧格式**（HTTPException）:
```json
{
  "detail": "路线图不存在"
}
```

**新格式**（自定义异常）:
```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "路线图不存在",
    "request_id": "req-123",
    "timestamp": "2026-01-07T10:00:00Z"
  }
}
```
