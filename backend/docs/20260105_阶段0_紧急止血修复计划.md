## 📋 执行摘要

### 核心目标

修复4个P0级别的致命缺陷，确保系统安全性和稳定性：

1. **WebSocket鉴权漏洞** - 任意用户可订阅任意任务进度，存在信息泄露风险
2. **中间件顺序错误** - CORS预检请求可能被错误处理，TraceID可能丢失
3. **Session泄漏风险** - BackgroundTasks使用请求级Session，导致连接泄漏
4. **Celery异步池问题** - 使用维护不活跃的`celery-pool-asyncio`，存在稳定性风险
5. **JWT无撤销机制** - 无法立即使Token失效，安全风险窗口长达24小时

### 关键风险

| 风险项 | 等级 | 后果 | 缓解措施 |
|--------|------|------|----------|
| WebSocket无鉴权 | 🔥高危 | 用户数据泄露 | 独立测试、灰度发布 |
| Session泄漏 | 🔥高危 | 连接池耗尽 | 先在测试环境验证 |
| Celery升级兼容性 | ⚠️警告 | Worker不稳定 | 保留回滚方案 |
| JWT黑名单性能 | ℹ️建议 | Redis压力增加 | 设置合理TTL |

### 任务1: WebSocket鉴权实现 [P0-Critical]

**问题描述**:
```python
# app/api/v1/websocket.py (当前代码)
@router.websocket("/ws/{task_id}")
async def websocket_endpoint(websocket: WebSocket, task_id: str):
    await manager.connect(websocket, task_id)
    # ❌ 无任何鉴权，任意用户可订阅任意task_id
```

**修复方案**:

```python
# app/api/v1/websocket.py (修复后)

from fastapi import WebSocket, Query, status
from jose import jwt, JWTError
from app.config.settings import settings
from app.db.repository_factory import get_repository_factory
import structlog

logger = structlog.get_logger()

@router.websocket("/ws/{task_id}")
async def websocket_endpoint(
    websocket: WebSocket,
    task_id: str,
    token: str = Query(None, description="JWT Token for authentication"),
):
    """
    WebSocket端点：订阅任务进度更新
    
    鉴权方式：通过Query参数传递JWT Token
    连接URL示例：ws://api.example.com/ws/task-123?token=eyJ...
    """
    # ===== 步骤1: 验证Token =====
    user_id = None
    if token:
        try:
            payload = jwt.decode(
                token,
                settings.JWT_SECRET_KEY,
                algorithms=[settings.JWT_ALGORITHM]
            )
            user_id = payload.get("sub")
            
            # 检查Token是否过期
            exp = payload.get("exp")
            if not exp or exp < time.time():
                await websocket.close(code=status.WS_1008_POLICY_VIOLATION)
                logger.warning("ws_token_expired", task_id=task_id)
                return
                
        except JWTError as e:
            await websocket.close(code=status.WS_1008_POLICY_VIOLATION)
            logger.warning("ws_auth_failed", task_id=task_id, error=str(e))
            return
    else:
        # 未提供Token
        await websocket.close(code=status.WS_1008_POLICY_VIOLATION)
        logger.warning("ws_no_token", task_id=task_id)
        return
    
    # ===== 步骤2: 验证用户有权访问该任务 =====
    repo_factory = get_repository_factory()
    async with repo_factory.create_session() as session:
        task_repo = repo_factory.create_task_repo(session)
        task = await task_repo.get_by_task_id(task_id)
        
        if not task:
            await websocket.close(code=status.WS_1003_UNSUPPORTED_DATA)
            logger.warning("ws_task_not_found", task_id=task_id, user_id=user_id)
            return
        
        if task.user_id != user_id:
            await websocket.close(code=status.WS_1008_POLICY_VIOLATION)
            logger.warning("ws_forbidden", task_id=task_id, user_id=user_id)
            return
    
    # ===== 步骤3: 建立连接 =====
    await manager.connect(websocket, task_id)
    logger.info("ws_connected", task_id=task_id, user_id=user_id)
    
    try:
        while True:
            # 保持连接活跃（接收客户端ping）
            data = await websocket.receive_text()
            if data == "ping":
                await websocket.send_text("pong")
    except WebSocketDisconnect:
        manager.disconnect(websocket, task_id)
        logger.info("ws_disconnected", task_id=task_id, user_id=user_id)
```

**验收标准**:
- [ ] 无Token连接被拒绝（WS 1008错误码）
- [ ] 过期Token被拒绝
- [ ] 非任务所有者被拒绝（Forbidden）
- [ ] 有效Token可正常订阅
- [ ] 前端WebSocket客户端已更新（带token参数）

### 任务2: 中间件顺序修正 [P0-High]

**问题描述**:
```python
# app/main.py (当前代码)
app.add_middleware(RequestIDMiddleware)  # ❌ 先添加（内层）
app.add_middleware(
    CORSMiddleware,  # ❌ 后添加（外层）
    allow_origins=settings.get_cors_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
# 实际执行顺序（请求）：CORS → RequestID
# 问题：CORS预检请求(OPTIONS)不会经过RequestID中间件
```

**修复方案**:

```python
# app/main.py (修复后)

from app.middleware.request_id import RequestIDMiddleware
from fastapi.middleware.cors import CORSMiddleware
import structlog

logger = structlog.get_logger()

def configure_middleware(app: FastAPI):
    """
    配置中间件栈（洋葱圈模型）
    
    执行顺序（请求进入）：
    CORS（最外层）→ RequestID → 业务逻辑
    
    执行顺序（响应返回）：
    业务逻辑 → RequestID → CORS（最外层）
    """
    
    # ===== 第1层：RequestID（内层）=====
    # 先添加，后执行
    app.add_middleware(RequestIDMiddleware)
    logger.info("middleware_registered", name="RequestIDMiddleware", layer=1)
    
    # ===== 第2层：CORS（外层）=====
    # 后添加，先执行（确保OPTIONS请求正确处理）
    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.get_cors_origins,
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"],
        expose_headers=["X-Request-ID"],  # ✅ 暴露RequestID给前端
    )
    logger.info("middleware_registered", name="CORSMiddleware", layer=2)

# 在app创建后调用
configure_middleware(app)
```

**原理说明**:

FastAPI/Starlette的中间件是**后添加先执行**（LIFO）：

```
请求流向：
Client → [CORS检查跨域] → [生成RequestID] → 路由处理
                ↑                   ↑
            后添加(外层)        先添加(内层)

响应流向：
路由处理 → [注入RequestID到响应头] → [添加CORS头] → Client
```

**验收标准**:
- [ ] OPTIONS预检请求返回正确的CORS头
- [ ] 所有请求响应头包含`X-Request-ID`
- [ ] 跨域请求可访问`X-Request-ID`头（expose_headers配置生效）
- [ ] 日志中所有请求都有request_id字段

### 任务3: BackgroundTasks Session修复 [P0-High]

**问题描述**:
```python
# app/api/v1/endpoints/cover_image.py (当前代码)
@router.post("/{roadmap_id}/cover-image/generate")
async def generate_cover_image(
    roadmap_id: str,
    background_tasks: BackgroundTasks,
    session: AsyncSession = Depends(get_db),  # ❌ 请求级Session
):
    # ... 验证逻辑
    
    # ❌ 致命错误：将请求级session透传到后台任务
    background_tasks.add_task(
        service.generate_cover_image,
        roadmap_id=roadmap_id,

        session=session,  # ❌ 请求结束后session已关闭

```

**后果推演**:
1. HTTP响应返回后，FastAPI关闭`session`
2. BackgroundTask异步执行时尝试使用已关闭的session
3. 触发`sqlalchemy.exc.InvalidRequestError: This session is closed`
4. 封面生成任务静默失败，用户永远看不到封面

**修复方案（方案A：改用Celery）**:

```python
# app/api/v1/endpoints/cover_image.py (修复后)

from app.tasks.cover_image_tasks import generate_cover_image_task

@router.post("/{roadmap_id}/cover-image/generate")
async def generate_cover_image(
    roadmap_id: str,
    request: GenerateCoverImageRequest,
    repo_factory: RepositoryFactory = Depends(get_repository_factory),
):
    """
    生成封面图（异步任务）
    
    改动：
    1. 不再使用BackgroundTasks（避免Session泄漏）
    2. 改用Celery异步任务（独立进程，独立Session）
    """
    # ===== 验证路线图存在且属于当前用户 =====
    async with repo_factory.create_session() as session:
        roadmap_repo = repo_factory.create_roadmap_meta_repo(session)
        roadmap = await roadmap_repo.get_by_roadmap_id(roadmap_id)
        
        if not roadmap:
            raise HTTPException(status_code=404, detail="Roadmap not found")
    
    # ===== 分发Celery任务 =====
    celery_task = generate_cover_image_task.delay(
        roadmap_id=roadmap_id,
        prompt=request.prompt or "Generate a modern learning roadmap cover",
    )
    
    logger.info(
        "cover_image_task_dispatched",
        roadmap_id=roadmap_id,
        celery_task_id=celery_task.id,
    )
    
    return {
        "message": "Cover image generation started",
        "task_id": celery_task.id,
        "status": "pending",
    }

"""
封面图生成Celery任务
"""
from app.core.celery_app import celery_app
from app.services.cover_image_service import CoverImageService
from app.db.repository_factory import get_repository_factory
import structlog

logger = structlog.get_logger()

@celery_app.task(
    name="cover_image.generate",
    bind=True,
    max_retries=3,
    default_retry_delay=10,
)
def generate_cover_image_task(self, roadmap_id: str, prompt: str):
    """
    封面图生成任务（Celery Worker）
    
    优势：
    1. 独立进程，独立数据库连接
    2. 支持重试
    3. 任务状态可追踪
    """
    try:
        # ✅ 在Worker进程中创建独立Session
        repo_factory = get_repository_factory()
        service = CoverImageService(repo_factory)
        
        # 执行同步包装的异步逻辑
        import asyncio
        result = asyncio.run(
            service.generate_cover_image(
                roadmap_id=roadmap_id,
                prompt=prompt,
            )
        )
        
        logger.info(
            "cover_image_generated",
            roadmap_id=roadmap_id,
            task_id=self.request.id,
            result=result,
        )
        
        return result
        
    except Exception as e:
        logger.error(
            "cover_image_generation_failed",
            roadmap_id=roadmap_id,
            error=str(e),
            exc_info=True,
        )
        # 自动重试
        raise self.retry(exc=e)
```

### 任务5: JWT黑名单机制 [P0-Medium]

**问题描述**:
- 当前JWT签发后无法撤销
- 用户登出后Token仍有效（最长24小时）
- 账号被盗后无法立即封禁

**修复方案**:

```python
# app/core/auth/jwt_blacklist.py (新建)
"""
JWT黑名单机制（基于Redis）
"""
from app.db.redis_client import redis_client
import structlog

logger = structlog.get_logger()

JWT_BLACKLIST_PREFIX = "jwt:blacklist:"

async def add_to_blacklist(jti: str, expires_in: int):
    """
    将Token加入黑名单
    
    Args:
        jti: JWT ID（唯一标识符）
        expires_in: Token剩余有效期（秒）
    
    原理：
    1. 使用Redis存储被撤销的Token ID
    2. 设置过期时间=Token剩余有效期
    3. Token过期后自动清理，无需手动删除
    """
    await redis_client.connect()
    key = f"{JWT_BLACKLIST_PREFIX}{jti}"
    
    # 使用setex设置带过期时间的键
    await redis_client._client.setex(key, expires_in, "1")
    
    logger.info("jwt_blacklisted", jti=jti, expires_in=expires_in)

async def is_blacklisted(jti: str) -> bool:
    """
    检查Token是否在黑名单中
    
    Args:
        jti: JWT ID
        
    Returns:
        True: 已撤销
        False: 有效
    """
    await redis_client.connect()
    key = f"{JWT_BLACKLIST_PREFIX}{jti}"
    exists = await redis_client._client.exists(key)
    return exists > 0

async def clear_user_tokens(user_id: str):
    """
    清除用户所有Token（强制登出）
    
    注意：需要在JWT中包含user_id字段才能使用
    """
    await redis_client.connect()
    pattern = f"{JWT_BLACKLIST_PREFIX}*:{user_id}:*"
    
    # 扫描匹配的键
    cursor = 0
    while True:
        cursor, keys = await redis_client._client.scan(
            cursor, match=pattern, count=100
        )
        if keys:
            await redis_client._client.delete(*keys)
        if cursor == 0:
            break
    
    logger.info("user_tokens_cleared", user_id=user_id)
```

```python
        )
        
        user_id: str = payload.get("sub")
        jti: str = payload.get("jti")  # ✅ JWT ID
        
        if user_id is None:
            raise HTTPException(
                status_code=status.HTTP_401_UNAUTHORIZED,
                detail="Invalid authentication credentials",
            )
        
        # ===== ⭐ 新增：检查黑名单 =====
        if jti and await is_blacklisted(jti):
            raise HTTPException(
                status_code=status.HTTP_401_UNAUTHORIZED,
                detail="Token has been revoked",
            )

    except JWTError:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Could not validate credentials",
        )
```

```python
# app/api/v1/endpoints/auth.py (新增登出接口)

@router.post("/logout")
async def logout(
    current_user: User = Depends(get_current_user),
    token: str = Depends(oauth2_scheme),
):
    """
    用户登出（撤销Token）
    """
    # 解码Token获取jti和过期时间
    payload = jwt.decode(
        token,
        settings.JWT_SECRET_KEY,
        algorithms=[settings.JWT_ALGORITHM]
    )
    
    jti = payload.get("jti")
    exp = payload.get("exp")
    
    if jti and exp:
        # 计算剩余有效期
        import time
        expires_in = max(int(exp - time.time()), 0)
        
        # 加入黑名单
        await add_to_blacklist(jti, expires_in)
    
    return {"message": "Successfully logged out"}
```

```python
async def is_blacklisted_batch(jtis: list[str]) -> dict[str, bool]:
```
