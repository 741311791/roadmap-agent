# API路径迁移清单

> **重构日期**: 2026-01-11  
> **架构变更**: 从扁平化API结构迁移到工作流驱动架构  
> **影响范围**: 前端所有API调用需要同步更新

---

## 一、架构变更概述

### 旧架构（扁平化）
所有API端点散落在 `/api/v1/` 根路径下

### 新架构（工作流驱动）
按业务领域分组：
- `/api/v1/workflows/generation/` - 路线图生成工作流
- `/api/v1/roadmaps/` - 路线图资源管理
- `/api/v1/content/` - 内容管理
- `/api/v1/learning/` - 学习体验
- `/api/v1/users/` - 用户与认证
- `/api/v1/admin/` - 平台管理

---

## 二、需要更新的API路径（15个）

**更新说明**: 
- intent、validation、edit 已从 workflows/generation 调整至 roadmaps 目录
- 对应的 service 层也已同步调整至 services/roadmaps/

### 工作流相关（2个）

| 旧路径 | 新路径 | HTTP方法 | 说明 |
|--------|--------|----------|------|
| `POST /api/v1/roadmaps/generate` | `POST /api/v1/workflows/generation/generate` | POST | 发起路线图生成 |
| `POST /api/v1/roadmaps/{task_id}/approve` | `POST /api/v1/workflows/generation/approve/{task_id}` | POST | 人工审核 |

### 路线图元数据（3个）

| 旧路径 | 新路径 | HTTP方法 | 说明 |
|--------|--------|----------|------|
| `GET /api/v1/intent-analysis/{task_id}` | `GET /api/v1/roadmaps/intent/{task_id}` | GET | 意图分析查询 |
| `GET /api/v1/tasks/{task_id}/validation-records` | `GET /api/v1/roadmaps/validation/{task_id}` | GET | 验证记录查询 |
| `GET /api/v1/tasks/{task_id}/edit-records` | `GET /api/v1/roadmaps/edit/{task_id}` | GET | 编辑记录查询 |

### 路线图资源（无变化）✅

以下路径保持不变：
- `GET /api/v1/roadmaps/{roadmap_id}`
- `GET /api/v1/roadmaps/{roadmap_id}/status`
- `GET /api/v1/roadmaps/{roadmap_id}/stream`
- `DELETE /api/v1/roadmaps/{roadmap_id}`
- `PUT /api/v1/roadmaps/{roadmap_id}`

### 内容管理（3个）

| 旧路径 | 新路径 | HTTP方法 | 说明 |
|--------|--------|----------|------|
| `GET /api/v1/roadmaps/{roadmap_id}/concepts/{concept_id}/tutorials` | `GET /api/v1/content/{roadmap_id}/concepts/{concept_id}/tutorials` | GET | 获取教程 |
| `POST /api/v1/roadmaps/{roadmap_id}/concepts/{concept_id}/tutorial/modify` | `POST /api/v1/content/{roadmap_id}/concepts/{concept_id}/tutorial/modify` | POST | 修改教程 |

### 学习体验（3个）

| `GET /api/v1/progress` | `GET /api/v1/learning/progress` | GET | 学习进度 |
| `POST /api/v1/mentor/chat` | `POST /api/v1/learning/mentor/chat` | POST | 伴学聊天 |
| `GET /api/v1/tech-assessments` | `GET /api/v1/learning/assessments` | GET | 技术评估 |

### 用户认证（2个）

| 旧路径 | 新路径 | HTTP方法 | 说明 |

## 三、前端更新建议

### 方案一：集中式API配置

在 `lib/api/config.ts` 中定义API路径常量：

```typescript
// API路径配置
export const API_PATHS = {
  // 工作流
  GENERATE_ROADMAP: '/api/v1/workflows/generation/generate',
  APPROVE_ROADMAP: (taskId: string) => `/api/v1/workflows/generation/approve/${taskId}`,
  INTENT_ANALYSIS: (taskId: string) => `/api/v1/workflows/generation/intent/${taskId}`,
  
  // 路线图资源
  GET_ROADMAP: (roadmapId: string) => `/api/v1/roadmaps/${roadmapId}`,
  
  // 学习体验
  PROGRESS: '/api/v1/learning/progress',
  MENTOR_CHAT: '/api/v1/learning/mentor/chat',
  ASSESSMENTS: '/api/v1/learning/assessments',
  
  // 用户
  LOGOUT: '/api/v1/users/auth/logout',
  WAITLIST: '/api/v1/users/waitlist',
}
```

### 方案二：API客户端重构

在 `lib/api/` 下按业务领域组织API客户端：

```
lib/api/
├── workflows/
│   └── generation.ts
├── roadmaps/
│   └── index.ts
├── content/
│   └── index.ts
├── learning/
│   └── index.ts
├── users/
│   └── index.ts
└── admin/
    └── index.ts
```
