## 技术实现

### 使用的技术栈
- **next-intl** v4.8.2 - 国际化库
- **LocaleProvider** - 客户端语言Provider
- **LanguageSwitcher** - 语言切换器组件

### 翻译文件结构
```
messages/
├── zh.json  - 中文翻译
└── en.json  - 英文翻译
```

### 语言切换流程
1. 用户点击语言切换器
2. 调用 `setLocale(newLocale)`
3. LocaleProvider动态加载新语言翻译文件
4. 更新React状态和Zustand Store
5. 持久化到localStorage和Cookie
6. 页面立即更新（无需刷新）

### 语言检测优先级
1. localStorage中的保存值
2. 浏览器语言检测
3. 默认值（'en'）
