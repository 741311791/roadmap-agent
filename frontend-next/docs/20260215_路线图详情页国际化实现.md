## 技术细节

### 国际化实现方式

使用 `next-intl` 库的 `useTranslations` hook:

```typescript
const t = useTranslations('roadmapDetail');
// 基本使用
t('loading')
// 带参数的翻译
t('overallCompletion', { progress: 75 })
t('resourcesCount', { count: 10 })
t('questionsCount', { count: 5 })
```

### 动态内容处理

**用户生成的内容不翻译**:
- `roadmap.title` - 路线图标题
- `concept.name` - 概念名称
- `concept.description` - 概念描述
- `question.question` - 测验问题
- `question.options` - 测验选项
- `resource.title` - 资源标题
- `resource.description` - 资源描述

**只翻译界面元素**:
- 按钮文本
- 标签文本
- 状态提示
- 错误消息
- 占位符文本
- 系统提示

### 数据格式化

**资源类型映射**:
```typescript
const getResourceTypeLabel = (type: string) => {
  switch (type) {
    case 'video': return t('video');
    case 'book': return t('book');
    case 'course': return t('course');
    default: return t('article');
  }
};
```

**难度级别映射**:
```typescript
const getDifficultyLabel = (difficulty: string) => {
  switch (difficulty) {
    case 'easy': return t('easy');
    case 'medium': return t('medium');
    case 'hard': return t('hard');
    default: return difficulty;
  }
};
```

**题型标签映射**:
```typescript
const getQuestionTypeLabel = () => {
  if (isTrueFalse) return t('trueFalse');
  if (isMultipleChoice) return t('selectAll');
  return t('chooseOne');
};
```
