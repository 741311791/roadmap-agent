# 前端换行符显示修复

**日期**: 2026-01-21  
**类型**: Bug 修复  
**影响范围**: Profile 页面 Assessment 对话框

## 问题描述

在 Profile 页面的 Assessment 对话框中，答案选项文本中包含的 `\n` 换行符没有被正确渲染，而是作为普通字符串 `\n` 显示出来。

**问题示例**：
```
显示：Operation attempted\nNo exception occurred\nResult: 5.0
期望：Operation attempted
     No exception occurred
     Result: 5.0
```

## 根本原因

1. **题目和选项渲染**：`QuestionMarkdown` 组件使用 `ReactMarkdown` 渲染，但 Markdown 需要特定语法（两个空格+换行）才能渲染换行符，单纯的 `\n` 不会被识别
2. **分析报告渲染**：`CapabilityAnalysisReport` 组件直接显示纯文本，没有使用 CSS 样式保留换行符

## 解决方案

### 1. 修复 `QuestionMarkdown` 组件
**文件**: `frontend-next/components/profile/assessment-questions.tsx`

**修改内容**：
- 在渲染前将 `\n` 转换为 Markdown 换行语法（两个空格 + `\n`）
- 添加 `br` 组件的自定义渲染

```typescript
function QuestionMarkdown({ content }: { content: string }) {
  // 处理换行符：将 \n 转换为 Markdown 换行（两个空格 + \n）
  const formattedContent = content.replace(/\n/g, '  \n');
  
  return (
    <ReactMarkdown
      remarkPlugins={[remarkGfm]}
      rehypePlugins={[rehypeHighlight]}
      components={{
        // ... 其他组件
        // 换行符渲染
        br() {
          return <br />;
        },
      }}
    >
      {formattedContent}
    </ReactMarkdown>
  );
}
```

### 2. 修复 `CapabilityAnalysisReport` 组件
**文件**: `frontend-next/components/profile/capability-analysis-report.tsx`

**修改内容**：
为所有文本显示元素添加 `whitespace-pre-wrap` CSS 类，保留换行符和空格

**修改位置**：
1. Overall Assessment（整体评价）
2. Strengths（优势列表）
3. Weaknesses（薄弱环节列表）
4. Knowledge Gaps - Description（知识缺口描述）
5. Knowledge Gaps - Recommendations（建议列表）
6. Learning Suggestions（学习建议列表）
7. Proficiency Verification - Reasoning（能力验证推理）

```tsx
// 示例：整体评价
<p className="text-sm text-muted-foreground leading-relaxed whitespace-pre-wrap">
  {result.overall_assessment}
</p>

// 示例：列表项
<span className="whitespace-pre-wrap">{strength}</span>
```

### 3. 修复 `AssessmentResult` 组件
**文件**: `frontend-next/components/profile/assessment-result.tsx`

**修改内容**：
为 Message 文本添加 `whitespace-pre-wrap` CSS 类

```tsx
<p className="text-sm text-muted-foreground whitespace-pre-wrap">
  {result.message}
</p>
```

## CSS `whitespace-pre-wrap` 说明

`whitespace-pre-wrap` 是 CSS 属性，作用：
- 保留空白符和换行符
- 文本会在遇到换行符、`<br>` 或填满容器宽度时自动换行
- 相当于 `white-space: pre-wrap`

**与其他值对比**：
- `normal`（默认）：折叠空白符，忽略换行符
- `pre`：保留空白符和换行符，但不自动换行
- `pre-wrap`：保留空白符和换行符，自动换行
- `pre-line`：折叠空白符，保留换行符，自动换行

## 测试验证

### 测试场景
1. **题目选项显示**：
   - 创建包含多行文本的测验题目
   - 验证选项中的换行符正确显示

2. **能力分析报告**：
   - 完成测验并查看能力分析报告
   - 验证所有文本字段的换行符正确显示

3. **评估结果**：
   - 查看评估结果消息
   - 验证消息中的换行符正确显示

### 预期结果
所有包含 `\n` 的文本内容应正确显示为换行，而不是字符串 `\n`

## 后续建议

1. **统一文本渲染组件**：考虑创建一个统一的 `TextWithLineBreaks` 组件，处理所有需要显示换行符的场景
2. **后端数据格式**：如果可能，建议后端统一返回 Markdown 格式或 HTML 格式的文本，前端统一处理
3. **组件文档**：为 `QuestionMarkdown` 组件添加使用文档，说明其换行符处理逻辑
