## 语言切换功能

### 架构方案
- **核心**：LocaleProvider（纯客户端Provider）
- **存储**：localStorage + Cookie双重持久化
- **检测**：优先级 localStorage > 浏览器语言 > 默认en
- **切换**：即时生效，无需页面刷新

### 切换入口（3个）
1. **SiteHeader**（营销页）- 右上角"EN"/"中"按钮
2. **LeftSidebar**（应用内）- 底部语言选择器
3. **Settings**（设置页）- Appearance卡片中的Language选项

### 按钮显示逻辑
- ✅ 界面英文时 → 显示"EN"（当前语言标识）
- ✅ 界面中文时 → 显示"中"（当前语言标识）

## 使用方式

### 组件中使用翻译
```typescript
import { useTranslations } from 'next-intl';

export function MyComponent() {
  const t = useTranslations('sectionName');
  
  return (
    <div>
      <h1>{t('title')}</h1>
      <p>{t('description')}</p>
    </div>
  );
}
```

### 获取当前语言
```typescript
import { useLocale } from 'next-intl';

export function MyComponent() {
  const locale = useLocale(); // 'en' | 'zh'
  
  const data = locale === 'zh' ? chineseData : englishData;
  
  return <div>{data}</div>;
}
```

### 手动切换语言
```typescript
import { useLocaleContext } from '@/components/providers/locale-provider';

export function MyComponent() {
  const { locale, setLocale } = useLocaleContext();
  
  return (
    <button onClick={() => setLocale(locale === 'en' ? 'zh' : 'en')}>
      Switch Language
    </button>
  );
}
```
