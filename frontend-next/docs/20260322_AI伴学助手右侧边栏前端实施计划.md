# AI 伴学助手右侧边栏 — 前端实施计划

## 一、目标概述

在路线图详情页（`app/(immersive)/roadmap/[id]/page.tsx`）的右侧新增一个可拖拽调整宽度的 AI 伴学助手面板，基于 `@assistant-ui/react` 的 `LocalRuntime` 实现，支持流式对话、多 Agent 切换、多模型选择、历史会话管理。

---

## 二、依赖安装

```bash
npm install @assistant-ui/react @assistant-ui/react-markdown
```

> `@assistant-ui/react` 提供 `useLocalRuntime`、`AssistantRuntimeProvider`、`ThreadPrimitive`、`ComposerPrimitive` 等核心原语组件。
> `@assistant-ui/react-markdown` 提供对话消息的 Markdown 渲染。
> 无需安装 `@assistant-ui/react-langgraph`，本项目使用 `LocalRuntime` 自定义适配。

## 五、核心组件设计

### 5.1 `use-mentor-runtime.ts` — LocalRuntime 适配器

```ts
// 伪代码示意
export function useMentorRuntime(options: MentorRuntimeOptions) {
  const adapter: ChatModelAdapter = {
    async run({ messages, abortSignal, config }) {
      // 调用后端 SSE 接口：POST /api/v1/learning/mentor/chat
      // 传入：messages、agent_type、model_id、context（roadmapId + conceptId）
      // 使用 @microsoft/fetch-event-source 接收流式响应
      // 通过 update() 回调逐步更新消息内容
    }
  };

  return useLocalRuntime(adapter);
}
```

流式响应数据格式（与后端约定）：

```
data: {"delta": "部分文本内容"}
data: {"delta": "更多内容"}
data: [DONE]
```

### 5.2 `mentor-sidebar.tsx` — 容器组件

```tsx
export function MentorSidebar({ roadmapId, activeConcept }) {
  const [agentType, setAgentType] = useState<'tutoring' | 'company'>('tutoring');
  const [modelId, setModelId] = useState('google/gemini-3.1-pro-preview');
  const { threads, currentThreadId, createThread, switchThread } = useMentorThreads();

  const runtime = useMentorRuntime({
    agentType,
    modelId,
    context: { roadmapId, conceptId: activeConcept?.id, conceptTitle: activeConcept?.name }
  });

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {/* Thread 主体 */}
      <MentorThread agentType={agentType} activeConcept={activeConcept} />
      {/* 底部工具栏 */}
      <MentorToolbar
        agentType={agentType}
        onAgentChange={setAgentType}
        modelId={modelId}
        onModelChange={setModelId}
        onOpenHistory={...}
        onNewThread={createThread}
      />
      {/* 历史会话抽屉 */}
      <MentorThreadHistory
        threads={threads}
        currentThreadId={currentThreadId}
        onSwitch={switchThread}
      />
    </AssistantRuntimeProvider>
  );
}
```

### 5.5 `use-mentor-threads.ts` — 历史会话管理

- 存储方式：`localStorage`，key 为 `mentor_threads_{roadmapId}`
- 最多保留 **10 条**历史线程，超出时自动删除最旧的
- 每条线程记录：`{ id, title, agentType, modelId, createdAt, messages[] }`
- `title` 取第一条用户消息的前 20 字符自动生成

```ts
interface MentorThread {
  id: string;
  title: string;
  agentType: 'tutoring' | 'company';
  modelId: string;
  conceptId?: string;
  conceptTitle?: string;
  createdAt: number;
  messages: SerializedMessage[];
}
```

## 七、assistant-ui 原语组件使用清单

| 组件 | 用途 |
|---|---|
| `useLocalRuntime` | 创建 LocalRuntime 实例 |
| `AssistantRuntimeProvider` | 将 Runtime 注入 Context |
| `ThreadPrimitive.Root` | 对话区域根容器 |
| `ThreadPrimitive.Viewport` | 可滚动消息列表区 |
| `ThreadPrimitive.Messages` | 消息渲染器（UserMessage + AssistantMessage） |
| `ThreadPrimitive.ScrollToBottom` | 滚动到底部按钮 |
| `ComposerPrimitive.Root` | 输入框容器（包裹章节标签 + 输入框） |
| `ComposerPrimitive.Input` | 输入框主体 |
| `ComposerPrimitive.Send` | 发送按钮 |
| `MessagePrimitive.Content` | 消息内容渲染区 |
| `AssistantIf` | 条件渲染（空状态欢迎页） |

**不使用**：`ThreadList`（用自研的 `MentorThreadHistory` 代替，以便 localStorage 持久化）

## 九、注意事项

1. **`company_agent.j2` 与 `tutorin_agent.j2` 目前内容相同**，开发前需先由后端完善 `company_agent.j2`（伴学 Agent 的系统提示词）
2. **章节上下文注入**：可将当前教程正文的前 500 字符作为 `context.tutorialContent` 传入，注入 system prompt 以让 AI 有参考依据
3. **模型 ID 格式**：与 OpenRouter 的 model ID 格式对齐，前端直接透传给后端
4. **流式消息的 abort**：切换 Agent/Model/Thread 时需调用 `abortController.abort()` 终止正在进行的流
5. **Local Runtime 消息持久化**：`LocalRuntime` 本身不持久化，所有历史会话消息需在 `use-mentor-threads.ts` 中手动序列化到 localStorage
