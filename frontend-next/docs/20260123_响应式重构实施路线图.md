**实现步骤**：
```tsx
import { ResponsiveSidebar } from '@/components/common';
import { useIsMobile } from '@/lib/hooks';

export function Navigation() {
  const isMobile = useIsMobile();
  
  const NavContent = () => (
    <nav className="flex flex-col md:flex-row gap-4 md:gap-6">
      <NavLink href="/dashboard">Dashboard</NavLink>
      <NavLink href="/roadmaps">Roadmaps</NavLink>
      <NavLink href="/tasks">Tasks</NavLink>
    </nav>
  );

  if (isMobile) {
    return <ResponsiveSidebar>{NavContent()}</ResponsiveSidebar>;
  }

  return <header><NavContent /></header>;
}
```

## 🚀 快速开始

### 1. 重构现有组件

**步骤**：
1. 确定组件类型（表格/对话框/侧边栏）
2. 选择对应的响应式包装器
3. 实现移动端和桌面端布局
4. 测试不同断点
5. 提交 PR

**示例**：重构任务列表
```bash
# 1. 创建新文件（保留原文件作为备份）
cp components/task/task-list.tsx components/task/task-list.backup.tsx

# 2. 参考示例文件
cat components/task/task-list-responsive.tsx

# 3. 集成 ResponsiveTable
# 4. 测试
npm run dev
# 在浏览器中打开 Chrome DevTools > Toggle device toolbar

# 5. 提交
git add components/task/task-list.tsx
git commit -m "refactor: 重构TaskList为响应式组件"
```

---

### 2. 创建新组件

**步骤**：
1. 从移动端开始设计
2. 使用响应式 Hooks
3. 使用预定义工具类名
4. 逐步增强到桌面端

**模板**：
```tsx
'use client';

import { useBreakpoint } from '@/lib/hooks';
import { containerClasses, typographyClasses } from '@/lib/utils/responsive';

export function MyNewComponent() {
  const { isMobile, isDesktop } = useBreakpoint();

  return (
    <div className={containerClasses.content}>
      <h1 className={typographyClasses.h1}>Title</h1>
      
      {isMobile && <MobileView />}
      {isDesktop && <DesktopView />}
    </div>
  );
}
```
