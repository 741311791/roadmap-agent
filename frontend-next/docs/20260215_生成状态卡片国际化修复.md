# 生成状态卡片国际化修复

**日期**: 2026-02-15  
**类型**: Bug修复  
**影响范围**: 路线图详情页内容生成状态显示

## 问题描述

路线图详情页中的内容生成状态卡片（`GeneratingContentLoader`组件）中存在硬编码的英文文本，未实现中英文切换功能。

### 硬编码文本

1. **内容类型标签**：`Tutorial`、`Learning Resources`、`Quiz Questions`
2. **动作动词**：`Generating`、`Fetching`
3. **等待提示**：`This may take a few moments. Please wait...`
4. **WebSocket提示**：`💡 Status updates are delivered in real-time via WebSocket`

## 解决方案

### 1. 添加国际化翻译

在 `messages/en.json` 和 `messages/zh.json` 中的 `roadmapDetail` 命名空间下添加 `generatingContent` 子对象：

```json
"generatingContent": {
  "tutorial": "Tutorial / 教程",
  "resources": "Learning Resources / 学习资源",
  "quiz": "Quiz Questions / 测验题目",
  "generatingVerb": "Generating / 生成中",
  "fetchingVerb": "Fetching / 获取中",
  "pleaseWait": "This may take a few moments. Please wait... / 这可能需要一些时间，请稍候...",
  "websocketHint": "💡 Status updates are delivered in real-time via WebSocket / 💡 状态更新通过WebSocket实时推送"
}
```

### 2. 修改组件实现

修改 `components/common/generating-content-loader.tsx`：

**关键改动**：

1. 引入 `useTranslations` Hook
2. 移除硬编码的 `CONTENT_TYPE_LABELS` 常量
3. 添加 `getContentName()` 和 `getVerb()` 辅助函数
4. 使用翻译函数替换所有硬编码文本

**代码结构**：

```typescript
export function GeneratingContentLoader({ contentType, className }: GeneratingContentLoaderProps) {
  const t = useTranslations('roadmapDetail.generatingContent');

  const getContentName = () => {
    switch (contentType) {
      case 'tutorial': return t('tutorial');
      case 'resources': return t('resources');
      case 'quiz': return t('quiz');
    }
  };

  const getVerb = () => {
    return contentType === 'resources' ? t('fetchingVerb') : t('generatingVerb');
  };

  // ... 渲染逻辑
}
```

## 技术细节

### 内容类型与动词映射

- `tutorial` → `Generating Tutorial / 生成中 教程`
- `resources` → `Fetching Learning Resources / 获取中 学习资源`
- `quiz` → `Generating Quiz Questions / 生成中 测验题目`

### 翻译命名空间

- **命名空间**: `roadmapDetail.generatingContent`
- **原因**: 该组件在路线图详情页（`roadmap/[id]/page.tsx`）中使用，归属于路线图详情页的子功能
