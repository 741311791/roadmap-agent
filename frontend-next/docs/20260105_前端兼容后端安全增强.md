## 🔧 详细修复

### 1. WebSocket 连接添加 Token 认证

**问题**：后端新增 WebSocket JWT 鉴权，未授权连接会被拒绝（WS 1008错误）

**修改文件**：
- `lib/api/websocket.ts`
- `lib/api/websocket/roadmap-ws.ts`

**改动**：
```typescript
// 旧版：无 Token
const wsUrl = `${wsBaseUrl}/api/v1/ws/${taskId}?include_history=${includeHistory}`;

// 新版：添加 Token 参数
const token = localStorage.getItem('access_token');
let wsUrl = `${wsBaseUrl}/api/v1/ws/${taskId}?include_history=${includeHistory}`;
if (token) {
  wsUrl += `&token=${encodeURIComponent(token)}`;
}
```

**安全增强**：
- ✅ 强制要求用户登录（无 Token 直接抛出异常）
- ✅ 验证用户身份和 Token 有效性
- ✅ 确认用户拥有任务访问权限
- ✅ 日志中隐藏 Token 信息（使用 `***` 替换）
- ✅ 快速失败策略（Fail Fast）：未登录立即报错，不再尝试连接

---

### 2. 更新登出 API Endpoint

**问题**：后端新增独立的登出端点，支持 JWT 黑名单机制

**修改文件**：
- `lib/services/auth-service.ts`

**改动**：
```typescript
// 旧版：错误的 endpoint
await apiClient.post('/auth/jwt/logout');  // ❌ 404 Not Found

// 新版：正确的 endpoint
await apiClient.post('/auth/logout');  // ✅ 会将 Token 加入黑名单
```

**功能增强**：
- ✅ Token 立即失效（加入 Redis 黑名单）
- ✅ 登出后无法使用旧 Token
- ✅ 更好的安全性

## 🎯 影响范围分析

### 破坏性变更

| 变更 | 影响 | 缓解措施 |
|------|------|----------|
| WebSocket 需要 Token | 未登录用户无法订阅任务 | 已实现：自动从 localStorage 获取 |
| 登出 endpoint 变更 | 旧代码 404 错误 | 已修复：更新为新 endpoint |

### 安全策略（Fail Fast）

- ✅ **强制认证** - 未登录用户直接抛出异常，不尝试连接
- ✅ **快速失败** - 立即发现问题，避免无效的网络请求
- ✅ **清晰错误** - 明确的错误信息，便于调试和用户引导
- ⚠️ **不支持匿名访问** - 所有 WebSocket 连接都需要有效的 JWT Token

## 📝 开发者注意事项

### Token 管理最佳实践

1. **不要在 URL 中记录完整 Token**：
```typescript
// ✅ 推荐
console.log(`Connecting to: ${url.replace(/token=[^&]+/, 'token=***')}`);

// ❌ 不推荐
console.log(`Connecting to: ${url}`);  // 会泄露 Token
```

2. **捕获认证异常**：
```typescript
try {
  const ws = new TaskWebSocket('task-123', handlers);
  ws.connect();
} catch (error) {
  if (error.message.includes('Authentication required')) {
    // 提示用户登录
    router.push('/login');
  }
}
```

3. **处理鉴权失败**：
```typescript
ws.onerror = (error) => {
  if (error.code === 1008) {  // Policy Violation
    // 提示用户重新登录
    authService.logout();
    router.push('/login');
  }
};
```

## 🐛 常见问题

### Q1: WebSocket 连接失败（1008 错误）

**原因**：Token 无效、过期或不存在

**解决**：
```typescript
// 检查 Token 是否存在
const token = localStorage.getItem('access_token');
console.log('Token exists:', !!token);

// 重新登录获取新 Token
authService.logoutAsync().then(() => {
  router.push('/login');
});
```

### Q2: 登出后仍然可以访问 API

**原因**：前端缓存了旧响应，或使用了本地 Token

**解决**：
```typescript
// 确保清除所有缓存
localStorage.clear();
sessionStorage.clear();

// 刷新页面
window.location.reload();
```

### Q3: WebSocket 日志显示完整 Token

**原因**：未正确隐藏 Token

**解决**：
```typescript
// 使用正则替换 Token
const safeUrl = url.replace(/token=[^&]+/, 'token=***');
console.log('Connecting to:', safeUrl);
```
