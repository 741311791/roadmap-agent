## 一、设计系统概览

### 1.1 断点系统

基于 Tailwind CSS 默认断点，与项目保持一致：

| 断点 | 最小宽度 | 设备类型 | 使用场景 |
|-----|---------|---------|---------|
| `xs` | 0px | 手机竖屏 | 默认样式（移动端优先）|
| `sm` | 640px | 手机横屏 | 大屏手机优化 |
| `md` | 768px | 平板竖屏 | iPad Mini, 小平板 |
| `lg` | 1024px | 平板横屏/小桌面 | iPad Pro, 笔记本 |
| `xl` | 1280px | 桌面 | 标准显示器 |
| `2xl` | 1536px | 大桌面 | 高分辨率显示器 |
| `wide` | 1920px+ | 宽屏 | 4K/超宽屏 |

### 1.2 核心 Hooks

```typescript
// 1. 基础断点检测
import { useIsMobile, useIsTablet, useIsDesktop, useIsWide } from '@/lib/hooks';

const isMobile = useIsMobile();    // < 768px
const isTablet = useIsTablet();    // 768px - 1023px
const isDesktop = useIsDesktop();  // >= 1024px
const isWide = useIsWide();        // >= 1920px

// 2. 设备类型检测
import { useDeviceType } from '@/lib/hooks';

const deviceType = useDeviceType(); // 'mobile' | 'tablet' | 'desktop' | 'wide'

// 3. 详细断点状态
import { useBreakpoint } from '@/lib/hooks';

const { width, height, isMobile, currentBreakpoint } = useBreakpoint();

// 4. 响应式值选择
import { useBreakpointValue } from '@/lib/hooks';

const columns = useBreakpointValue({
  xs: 1,
  sm: 2,
  md: 3,
  lg: 4,
  default: 1,
});
```

### 1.3 工具函数

## 二、组件重构模式

### 2.1 表格组件（Table）

#### 问题
- 固定列宽在移动端溢出
- 横向滚动体验差
- 操作按钮挤压

#### 解决方案：适应式设计

**移动端：卡片布局**
```tsx
import { useIsMobile } from '@/lib/hooks';

export function TaskList({ tasks }: TaskListProps) {
  const isMobile = useIsMobile();

  if (isMobile) {
    return <TaskCardList tasks={tasks} />;
  }

  return <TaskTable tasks={tasks} />;
}

// 移动端卡片视图
function TaskCardList({ tasks }: { tasks: Task[] }) {
  return (
    <div className="space-y-4">
      {tasks.map((task) => (
        <Card key={task.id} className="p-4">
          <div className="flex items-start justify-between mb-2">
            <h3 className="font-semibold truncate">{task.title}</h3>
            <Badge>{task.status}</Badge>
          </div>
          <div className="text-sm text-muted-foreground space-y-1">
            <div>Step: {task.currentStep}</div>
            <div>Created: {formatDate(task.createdAt)}</div>
          </div>
          <div className="flex gap-2 mt-3">
            <Button size="sm" variant="ghost">View</Button>
            <Button size="sm" variant="ghost">Retry</Button>
          </div>
        </Card>
      ))}
    </div>
  );
}

// 桌面端表格视图
function TaskTable({ tasks }: { tasks: Task[] }) {
  return (
    <Table>
      {/* 标准表格布局 */}
    </Table>
  );
}
```

**平板/桌面：响应式表格**
```tsx
// 使用 min-width 而非固定宽度
<TableHead className="min-w-[200px]">Task Title</TableHead>
<TableHead className="min-w-[120px]">Status</TableHead>

// 或使用相对宽度
<TableHead className="w-[30%]">Task Title</TableHead>
<TableHead className="w-[15%]">Status</TableHead>
```

### 2.2 侧边栏组件（Sidebar）

#### 问题
- 固定侧边栏占用移动端宽度
- 导航层级过深
- 切换不便

#### 解决方案：Sheet/Drawer

**移动端：抽屉式侧边栏**
```tsx
import { Sheet, SheetContent, SheetTrigger } from '@/components/ui/sheet';
import { useIsMobile } from '@/lib/hooks';

export function AppSidebar() {
  const isMobile = useIsMobile();

  const SidebarContent = () => (
    <nav className="space-y-2 p-4">
      {/* 导航内容 */}
    </nav>
  );

  if (isMobile) {
    return (
      <Sheet>
        <SheetTrigger asChild>
          <Button variant="ghost" size="icon">
            <Menu className="h-5 w-5" />
          </Button>
        </SheetTrigger>
        <SheetContent side="left" className="w-[280px]">
          <SidebarContent />
        </SheetContent>
      </Sheet>
    );
  }

  // 桌面端：固定侧边栏
  return (
    <aside className="w-64 border-r bg-card">
      <SidebarContent />
    </aside>
  );
}
```

**平板/桌面：可折叠侧边栏**
```tsx
'use client';

import { useState } from 'react';
import { useIsDesktop } from '@/lib/hooks';

export function CollapsibleSidebar() {
  const isDesktop = useIsDesktop();
  const [collapsed, setCollapsed] = useState(false);

  if (!isDesktop) return null; // 移动端用 Sheet

  return (
    <aside 
      className={cn(
        'border-r bg-card transition-all duration-300',
        collapsed ? 'w-16' : 'w-64'
      )}
    >
      <Button 
        variant="ghost" 
        size="icon"
        onClick={() => setCollapsed(!collapsed)}
        className="m-2"
      >
        {collapsed ? <ChevronRight /> : <ChevronLeft />}
      </Button>
      {/* 侧边栏内容 */}
    </aside>
  );
}
```

### 2.3 对话框组件（Dialog）

#### 问题
- 固定宽度在移动端被裁剪
- 内容溢出
- 操作按钮布局混乱

#### 解决方案：响应式对话框

```tsx
import { Dialog, DialogContent } from '@/components/ui/dialog';
import { Sheet, SheetContent } from '@/components/ui/sheet';
import { useIsMobile } from '@/lib/hooks';

export function ResponsiveDialog({ 
  open, 
  onOpenChange, 
  children 
}: ResponsiveDialogProps) {
  const isMobile = useIsMobile();

  if (isMobile) {
    // 移动端：全屏 Sheet（从底部弹出）
    return (
      <Sheet open={open} onOpenChange={onOpenChange}>
        <SheetContent 
          side="bottom" 
          className="h-[90vh] rounded-t-2xl"
        >
          {children}
        </SheetContent>
      </Sheet>
    );
  }

  // 桌面端：居中对话框
  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-w-2xl">
        {children}
      </DialogContent>
    </Dialog>
  );
}
```

**响应式按钮布局**
```tsx
// 移动端：垂直堆叠，桌面端：水平排列
<div className="flex flex-col md:flex-row gap-2 md:gap-4 mt-6">
  <Button className="w-full md:w-auto">Confirm</Button>
  <Button variant="outline" className="w-full md:w-auto">Cancel</Button>
</div>
```

### 2.4 卡片网格（Card Grid）

#### 问题
- 固定列数导致移动端卡片过小
- 间距不统一
- 图片加载缓慢

#### 解决方案：自适应网格

```tsx
// 使用预定义的网格类名
import { gridClasses } from '@/lib/utils/responsive';

<div className={gridClasses.cards}>
  {/* grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 */}
  {roadmaps.map((roadmap) => (
    <RoadmapCard key={roadmap.id} roadmap={roadmap} />
  ))}
</div>

// 或自定义列数
<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 2xl:grid-cols-4 gap-4 md:gap-6">
  {items.map((item) => <Card key={item.id} {...item} />)}
</div>
```

**响应式卡片内容**
```tsx
<Card className="overflow-hidden">
  {/* 封面图 */}
  <div className="aspect-video md:aspect-[16/10] lg:aspect-video">
```

### 2.5 导航组件（Navigation）

#### 问题
- 桌面端导航在移动端溢出
- 汉堡菜单过深
- 子菜单层级复杂

#### 解决方案：适应式导航

```tsx
'use client';

import { useIsMobile } from '@/lib/hooks';
import { Sheet, SheetContent, SheetTrigger } from '@/components/ui/sheet';
import { Menu } from 'lucide-react';

export function Navigation() {
  const isMobile = useIsMobile();

  const NavLinks = () => (
    <>
      <NavLink href="/dashboard">Dashboard</NavLink>
      <NavLink href="/roadmaps">Roadmaps</NavLink>
      <NavLink href="/tasks">Tasks</NavLink>
      <NavLink href="/profile">Profile</NavLink>
    </>
  );

  if (isMobile) {
    return (
      <Sheet>
        <SheetTrigger asChild>
          <Button variant="ghost" size="icon">
            <Menu className="h-6 w-6" />
          </Button>
        </SheetTrigger>
        <SheetContent side="left" className="w-[280px]">
          <nav className="flex flex-col gap-4 mt-8">
            <NavLinks />
          </nav>
        </SheetContent>
      </Sheet>
    );
  }

  // 桌面端：水平导航
  return (
    <nav className="hidden md:flex items-center gap-6">
      <NavLinks />
    </nav>
  );
}

function NavLink({ href, children }: { href: string; children: React.ReactNode }) {
  return (
    <Link 
      href={href}
      className="text-sm md:text-base font-medium hover:text-sage-600 transition-colors"
    >
      {children}
    </Link>
  );
}
```

## 三、最佳实践

### 3.1 移动端优先（Mobile First）

**始终从移动端开始设计**
```tsx
// ✅ 正确：移动端默认，逐步增强
<div className="p-4 md:p-6 lg:p-8 xl:p-10">
  <h1 className="text-2xl md:text-3xl lg:text-4xl">Title</h1>
</div>

// ❌ 错误：桌面端默认，向下适配
<div className="p-10 md:p-6 sm:p-4">
  <h1 className="text-4xl md:text-3xl sm:text-2xl">Title</h1>
</div>
```

### 3.2 触摸友好

**移动端增大触摸目标**
```tsx
// 按钮最小高度 44px（iOS 标准）
<Button 
  className="h-11 md:h-10 px-6 md:px-4"
  size="lg" // 移动端使用大按钮
>
  Tap Here
</Button>

// 增加间距，避免误触
<div className="flex flex-col gap-4 md:flex-row md:gap-2">
  <Button>Action 1</Button>
  <Button>Action 2</Button>
</div>
```

### 3.3 性能优化

**条件渲染而非隐藏**
```tsx
// ✅ 正确：不渲染不需要的组件
const isMobile = useIsMobile();

return (
  <>
    {isMobile ? <MobileView /> : <DesktopView />}
  </>
);

// ❌ 错误：渲染后隐藏（浪费资源）
return (
  <>
    <div className="block md:hidden"><MobileView /></div>
    <div className="hidden md:block"><DesktopView /></div>
  </>
);
```

**响应式图片加载**
```tsx
<Image
  src={imageUrl}
  alt="Cover"
  fill
  sizes="(max-width: 768px) 100vw, (max-width: 1024px) 50vw, 33vw"
  // 移动端加载小图，桌面端加载大图
/>
```

### 3.4 文本可读性

**响应式行长度**
```tsx
// 限制行宽，提升可读性
<article className="max-w-none md:max-w-2xl lg:max-w-4xl mx-auto">
  <p className="text-sm md:text-base lg:text-lg leading-relaxed">
    Long paragraph text...
  </p>
</article>
```

### 3.5 避免横向滚动

**容器溢出处理**
```tsx
// ✅ 正确：overflow-x-auto + min-width
<div className="overflow-x-auto">
  <Table className="min-w-[600px]">
    {/* 表格内容 */}
  </Table>
</div>

// ✅ 更好：移动端使用卡片
const isMobile = useIsMobile();
return isMobile ? <CardList /> : <Table />;
```

### 4.1 创建响应式组件

在 `components/common/` 下创建响应式包装组件：

```tsx
// components/common/responsive-dialog.tsx
export function ResponsiveDialog(props: ResponsiveDialogProps) {
  const isMobile = useIsMobile();
  return isMobile ? <Sheet {...props} /> : <Dialog {...props} />;
}

// components/common/responsive-table.tsx
export function ResponsiveTable<T>(props: ResponsiveTableProps<T>) {
  const isMobile = useIsMobile();
  return isMobile ? <CardList {...props} /> : <Table {...props} />;
}
```

## 八、常见问题

### Q1: SSR 下 useMediaQuery 报错？
**A**: 已处理，Hook 内部有 `typeof window === 'undefined'` 检查。

### Q2: 移动端和桌面端切换时闪烁？
**A**: 使用 SSR 默认值（桌面端），避免初始渲染不一致。

### Q3: 表格在移动端性能差？
**A**: 使用条件渲染 `isMobile ? <CardList /> : <Table />`，而非 `display: none`。

### Q4: 如何测试不同设备？
**A**: 使用 Chrome DevTools 设备模拟器 + 真机测试关键流程。
