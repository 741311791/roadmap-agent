# 新建路线图页面预设目标按钮功能

**日期**: 2026-02-16

## 概述

为 `/new` 页面的学习目标输入框下方添加了6个预设学习目标按钮，用户点击后可以自动填充详细的学习目标内容，大幅提升用户体验和表单填写效率。

## 功能特点

### 预设学习目标

提供6个热门学习方向的预设目标：

1. **全栈开发** (Full-Stack Development)
   - 涵盖 React、Node.js、Express、PostgreSQL
   - 从前端到后端的完整Web应用开发

2. **数据科学与机器学习** (Data Science & ML)
   - Python、NumPy、Pandas、scikit-learn、TensorFlow/PyTorch
   - 数据分析和机器学习管道构建

3. **移动应用开发** (Mobile Development)
   - React Native 或 Flutter
   - iOS/Android 跨平台应用开发

4. **DevOps与云计算** (DevOps & Cloud)
   - Docker、Kubernetes、CI/CD、AWS/Azure
   - 自动化部署和基础设施管理

5. **UI/UX设计** (UI/UX Design)
   - Figma、设计原则、用户研究
   - 从线框图到高保真原型的完整设计流程

6. **网络安全** (Cybersecurity)
   - 道德黑客、渗透测试、OWASP Top 10
   - 系统安全和漏洞防护

## 修改文件

### 1. 国际化配置

#### `frontend-next/messages/en.json`

在 `newRoadmap` 配置项中新增：

```json
{
  "quickStart": "Quick Start",
  "presetGoals": {
    "fullstack": {
      "label": "Full-Stack Development",
      "content": "详细的学习目标描述..."
    },
    "datascience": {
      "label": "Data Science & ML",
      "content": "详细的学习目标描述..."
    },
    // ... 其他预设目标
  }
}
```

每个预设目标包含：
- `label`: 按钮上显示的简短标签
- `content`: 点击后填充到输入框的详细内容（100-150字）

#### `frontend-next/messages/zh.json`

提供对应的中文翻译，所有预设目标的内容都经过本地化处理。

### 2. 组件修改

#### `frontend-next/app/(app)/new/new-roadmap-client.tsx`

**新增常量定义**（第59-66行）:
```typescript
const presetGoals = [
  'fullstack',
  'datascience',
  'mobile',
  'devops',
  'design',
  'security',
] as const;
```

**预设按钮UI**（第391-414行）:
```typescript
{/* Preset Goals */}
<div className="mt-3">
  <div className="text-xs font-medium text-muted-foreground mb-2">
    {t('newRoadmap.quickStart')}
  </div>
  <div className="flex flex-wrap gap-2">
    {presetGoals.map((goalId) => (
      <button
        key={goalId}
        type="button"
        onClick={() => {
          setFormData({
            ...formData,
            learningGoal: t(`newRoadmap.presetGoals.${goalId}.content`),
          });
        }}
        className="px-3 py-1.5 text-xs font-medium rounded-md border border-sage-200 bg-white hover:bg-sage-50 hover:border-sage-300 transition-colors text-sage-700"
      >
        {t(`newRoadmap.presetGoals.${goalId}.label`)}
      </button>
    ))}
  </div>
</div>
```

## UI设计

### 布局位置
- 位于学习目标输入框（textarea）正下方
- 与输入框保持适当间距（`mt-3`）

### 样式设计
- **标题**：`quickStart` 提示文字，小号字体，灰色
- **按钮**：
  - 小号按钮（`text-xs`，`py-1.5`，`px-3`）
  - 圆角设计（`rounded-md`）
  - 白色背景 + 淡绿色边框
  - Hover 效果：背景变为淡绿色，边框加深
  - 自动换行布局（`flex-wrap`）

### 交互行为
1. 用户点击任意预设按钮
2. 输入框自动填充对应的详细学习目标
3. 用户可以继续编辑填充的内容
4. 支持多次点击不同预设（替换内容）

## 技术实现

### 国际化支持
- 所有预设目标的标签和内容都支持中英文切换
- 使用 `t()` 函数动态获取翻译
- 模板字符串动态拼接键名：`` t(`newRoadmap.presetGoals.${goalId}.label`) ``

### 状态管理
- 点击按钮触发 `setFormData` 更新 `learningGoal` 字段
- 使用展开运算符保留其他表单字段的值
- 输入框通过 `value` 绑定立即反映变化

### 类型安全
- 使用 `as const` 断言确保预设目标ID的类型安全
- TypeScript 会在编译时检查国际化键名的正确性

## 用户体验优化

### 优点
1. **快速开始**：新用户无需从零编写学习目标
2. **参考示例**：展示了高质量学习目标的编写方式
3. **节省时间**：一键填充详细的学习路径描述
4. **灵活编辑**：填充后仍可自由修改内容
5. **多样选择**：涵盖6个热门技术方向
6. **国际化**：中英文用户都能获得本地化体验

### 使用场景
- 新用户不知道如何描述学习目标
- 用户想快速体验产品功能
- 用户的目标恰好属于预设类别之一
- 用户希望参考高质量的目标描述格式

## 内容质量

### 预设目标特点
- **具体明确**：列出具体的技术栈和工具
- **目标导向**：说明想要达成的能力水平
- **结构完整**：包含学习内容和应用场景
- **长度适中**：100-150字，既详细又不冗长
- **专业性**：使用行业标准术语
- **可操作**：描述可衡量的学习成果

### 内容示例（Full-Stack Development）

**英文**：
> I want to become a full-stack web developer proficient in both frontend and backend technologies. I'd like to learn React for building modern user interfaces, Node.js and Express for server-side development, and PostgreSQL for database management. My goal is to build complete web applications from scratch, including authentication, API design, and deployment on cloud platforms.

**中文**：
> 我想成为一名精通前端和后端技术的全栈Web开发者。我希望学习React来构建现代化用户界面，掌握Node.js和Express进行服务端开发，以及PostgreSQL进行数据库管理。我的目标是能够从零开始构建完整的Web应用，包括用户认证、API设计和云平台部署。
